# 커널 기법 2: 소프트 마진 SVM 및 서포트 벡터 회귀(SVR)의 핵심 원리와 구현 분석

## 핵심 요약 (Executive Summary)

* 현실적 데이터 대응을 위한 유연성 확보: 하드 마진 SVM은 완벽한 선형 분리를 가정하여 현실의 노이즈 데이터에서 과적합(Overfitting)되거나 학습이 불가능한 한계가 있습니다. 이를 해결하기 위해 **슬랙 변수(Slack Variables)**를 도입하여 분류 경계 침범을 허용하는 소프트 마진 SVM이 제안되었습니다.
* 트레이드오프 제어: 하이퍼파라미터 **C**는 마진의 크기와 오분류 허용 정도 사이의 균형을 조절합니다. C가 클수록 오분류를 엄격히 제한하며, 작을수록 더 넓은 마진을 허용하여 일반화 성능을 높입니다.
* 회귀 문제로의 확장: **서포트 벡터 회귀(SVR)**는 SVM의 개념을 연속값 예측으로 확장한 모델입니다. **$\epsilon$-불감 손실 함수($\epsilon$-insensitive loss function)**를 사용하여 일정 범위($\epsilon$-튜브) 내의 오차는 무시하고, 범위를 벗어난 데이터에 대해서만 비용을 부여함으로써 모델의 강건성(Robustness)을 확보합니다.
* 최적화 및 실무적 안정성: 두 모델 모두 KKT 조건을 만족하는 라그랑주 승수를 구하는 듀얼 문제로 변환하여 최적화합니다. 특히 절편 b를 계산할 때 여러 서포트 벡터의 결과값을 평균 내어 사용하는 방식이 모델의 안정성을 위해 권장됩니다.

## 1. 소프트 마진 SVM (Soft Margin SVM): 현실적 데이터 분류

### 1.1 하드 마진 SVM의 한계와 슬랙 변수 도입

하드 마진 SVM은 데이터를 완벽하게 분리할 수 있다는 이상적인 가정을 전제로 합니다. 하지만 현실 데이터는 노이즈가 포함되어 있거나 클래스가 겹치는 경우가 많아 다음과 같은 문제가 발생합니다.

* 과적합(Overfitting): 모델이 데이터에 지나치게 밀착하여 일반화 성능이 저하됨.
* 학습 불가: 선형적으로 분리되지 않는 데이터셋의 경우 모델 학습 자체가 불가능함.

**슬랙 변수($\xi_n$)**는 샘플이 분류 마진을 침범하거나 잘못 분류되는 정도를 정량화하여 이를 허용합니다.

* $\xi_n = 0$: 마진을 침범하지 않고 올바르게 분류된 상태.
* $\xi_n > 0$: 마진을 침범했거나 오분류된 상태(값이 클수록 심각도가 높음).

### 1.2 소프트 마진 SVM의 수학적 최적화

소프트 마진 SVM은 마진 최대화와 오분류 비용 최소화를 동시에 달성하는 것을 목표로 하며, 이를 C-SVM이라고도 부릅니다.

|항목|설명|
|---|---|
|프라이멀 문제|마진 크기 조절 항($\frac{1}{2}|w|^2$)과 비용 항($C \sum \xi_n$)의 합을 최소화함.|
|하이퍼파라미터 C|트레이드오프 상수로, C가 크면 하드 마진 SVM과 유사해지며 오분류에 민감해짐.|
|듀얼 문제의 제약 조건|라그랑주 승수 $\alpha_n$의 범위가 $0 \le \alpha_n \le C$로 제한됨 (박스 제약 조건).

## 2. 서포트 벡터 회귀 (SVR): 연속값 예측의 최적화

### 2.1 $\epsilon$-불감 손실 함수와 강건성

SVR은 회귀 예측선 주변에 $\epsilon$-튜브를 설정하는 독특한 접근법을 취합니다. 튜브 내부에서 발생하는 오차는 손실로 간주하지 않으며, 오직 튜브를 벗어난 데이터 포인트에 대해서만 그 초과분에 비례하는 비용을 부여합니다. 이 방식은 불필요한 미세 오차에 민감하게 반응하지 않도록 하여 모델의 강건성을 높입니다.

### 2.2 SVR의 프라이멀 문제와 슬랙 변수

SVR에서는 튜브의 상단과 하단을 벗어나는 손실을 각각 측정하기 위해 두 종류의 슬랙 변수를 도입합니다.

* $\xi_n$: 튜브 상단을 벗어난 정도.
* $\hat{\xi}_n$: 튜브 하단을 벗어난 정도.
* 목표 함수: 모델의 복잡도(기울기 w)를 최소화하면서, 튜브 외부 샘플의 손실($\xi_n + \hat{\xi}_n$)을 최소화함.


--------------------------------------------------------------------------------


## 3. 최적화 알고리즘 및 KKT 조건

모델의 최적 파라미터를 도출하기 위해 라그랑지안(Lagrangian) 미분을 통한 KKT(Karush-Kuhn-Tucker) 조건을 적용합니다.

1. 정상성(Stationarity): 라그랑지안을 각 변수로 미분했을 때 기울기가 0이 되어야 함.
2. 프라이멀 타당성(Primal Feasibility): 원래 문제의 제약 조건을 만족해야 함.
3. 듀얼 타당성(Dual Feasibility): 라그랑주 승수($\alpha_n$, $\mu_n$ 등)가 양수 조건을 만족해야 함.
4. 상호 보완성(Complementary Slackness): 서포트 벡터를 식별하는 핵심 조건으로, 제약 조건과 승수 중 하나는 반드시 0이어야 함.


--------------------------------------------------------------------------------


## 4. 실무 구현 및 하이퍼파라미터 튜닝

### 4.1 결정 경계 및 절편 b의 계산

최적화 과정을 통해 구한 라그랑주 승수 중 0 < $\alpha_n$ < C 범위를 만족하는 샘플들이 서포트 벡터가 됩니다.

* 안정적 b 계산: 이론적으로는 하나의 서포트 벡터로도 b를 구할 수 있으나, 실무적으로는 여러 서포트 벡터에서 계산된 b값들을 평균 내어 사용함으로써 모델의 신뢰도를 높입니다.

### 4.2 주요 하이퍼파라미터의 영향 분석

|하이퍼파라미터|영향 및 특징|
|---|---|
|C (Cost)|값이 클수록 오차를 강하게 억제하여 복잡한 모델을 생성하나, 과적합 위험이 증가함.|
|$\epsilon$ (Epsilon)|(SVR 전용) 튜브의 폭을 결정함. 클수록 모델이 단순해지고 작은 오차를 무시함.|
|$\gamma$ (Gamma)|RBF 커널 사용 시 데이터 간 유사도 계산 범위를 조절함. 클수록 결정 경계가 국소적으로 형성되어 복잡해짐.|


--------------------------------------------------------------------------------


## 5. 결론 및 시사점

소프트 마진 SVM과 SVR은 현실의 불완전한 데이터를 효과적으로 처리할 수 있는 강력한 기계학습 도구입니다. 슬랙 변수의 도입은 모델에 유연성을 부여하며, 하이퍼파라미터 C, $\epsilon, \gamma$의 적절한 튜닝은 일반화 성능 극대화의 핵심 요소입니다. 특히 RBF 커널을 활용하면 비선형 데이터의 복잡한 패턴도 매끄럽게 학습할 수 있으며, 튜브 내부 오차를 무시하는 SVR의 특성은 데이터 노이즈에 강한 예측 모델 구축을 가능하게 합니다.
