# 선형 판별 분석(LDA)

## 핵심 요약 (Executive Summary)

본 문서는 선형 분류의 기초가 되는 **결정 초평면(Decision Hyperplane)**의 개념과 이를 바탕으로 데이터를 최적으로 분류하는 **피셔의 선형 판별 분석(LDA)**의 이론 및 확장 방법을 분석합니다.

LDA의 핵심 목표는 고차원 데이터를 저차원(주로 1차원)으로 투영했을 때, 클래스 간 거리는 최대화하고 클래스 내부 분산은 최소화하는 최적의 방향(W)을 찾는 것입니다. 이 과정은 이진 분류에서 다중 클래스 분류로 확장될 수 있으며, 라그랑주 승수법과 고유값 분해(EVD)와 같은 수학적 최적화 도구를 통해 해결됩니다. 분석 결과, LDA는 단순한 차원 축소를 넘어 클래스 간의 구분을 명확히 유지하는 강력한 선형 분류 도구임을 확인하였습니다.


--------------------------------------------------------------------------------


## 1. 결정 초평면 (Decision Hyperplane)

결정 초평면은 선형 분류에서 데이터를 나누는 중요한 기준점이 됩니다.

* 정의 및 차원: 데이터가 존재하는 공간보다 한 단계 낮은 차원의 공간을 의미합니다.
  * 2차원 평면 데이터 → 1차원 직선
  * 3차원 공간 데이터 → 2차원 평면
  * 4차원 이상의 고차원 데이터 → 초평면(Hyperplane)
* 수학적 표현: 결정 초평면은 다음의 식으로 정의됩니다.
  * $W^T x + w_0$ = 0
  * W: 초평면의 법선 벡터(Normal Vector). 초평면 상의 임의의 두 점 $x_1, x_2$에 대해 ($x_2 - x_1$)과 W의 내적은 0이며, 이는 W가 초평면에 수직임을 증명합니다.
  * $w_0$: 바이어스(Bias)를 담당하는 스칼라 값.
  * x: 입력 벡터.
* 점과 초평면 사이의 거리: 임의의 점 x^*에서 초평면까지의 최단 거리는 점과 직선 사이의 거리 공식을 확장하여 계산할 수 있습니다.
  * 공식: $\frac{|W^T x^* + w_0|}{||W||}$
  * 이 거리는 특정 데이터 점이 결정 경계로부터 얼마나 멀리 떨어져 있는지를 판단하는 지표가 됩니다.

## 2. 피셔의 선형 판별 분석 (LDA: Linear Discriminant Analysis)

LDA는 고차원 데이터를 1차원 축으로 투영하여 두 클래스가 최대한 잘 나누어지도록 하는 방향(W)을 찾는 이진 분류 기법입니다.

### 2.1 핵심 목표

1. 클래스 간 평균 거리 최대화: 투영된 두 클래스의 평균값(m_1, m_2)이 서로 최대한 멀리 떨어져야 합니다.
2. 클래스 내 변동성(분산) 최소화: 각 클래스 내부의 데이터들이 투영될 때 너무 퍼지지 않고 뭉쳐 있어야 클래스 간 섞임이 최소화됩니다.

### 2.2 산포 행렬(Scatter Matrix)의 정의

LDA의 성능 지표를 수식화하기 위해 다음의 두 행렬을 사용합니다.

|구분|용어|수학적 의미|
|---|---|---|
|클래스 간 산포|$S_B$ (Between-class)|$(M_2 - M_1)(M_2 - M_1)^T$ (평균 차이 벡터의 외적/Outer Product)|
|클래스 내 산포|$S_W$ (Within-class)|$S_1 + S_2$ (각 클래스 내부 편차 제곱합의 합계)|

### 2.3 성능 지표 (Performance Index)

LDA는 다음의 성능 지표를 최대화하는 W를 찾습니다.

* 성능 지표 $J(W) = \frac{(m_2 - m_1)^2}{s_1^2 + s_2^2} = \frac{W^T S_B W}{W^T S_W W}$
* 이 식은 투영된 평균 차이의 제곱을 각 클래스 내부 분산의 합으로 나눈 형태입니다.

## 3. 최적화 및 수치 해석

LDA에서 방향 벡터 W를 구하는 과정은 수학적 최적화 기법을 따릅니다.

### 3.1 라그랑주 승수법 (Lagrange Multipliers)

방향 벡터 W는 크기보다 방향이 중요합니다. 따라서 계산의 편의를 위해 분모($W^T S_W W$)를 1로 고정하는 제약 조건을 두고, 분자($W^T S_B W$)를 최대화하는 문제로 변환합니다.

* 최적화 결과: $S_B W = \lambda S_W W$
* 최종 해: $W \propto S_W^{-1}(M_2 - M_1)$
* 즉, 최적의 투영 축은 두 클래스 평균의 차이에 클래스 내 산포 행렬의 역행렬을 곱하여 보정한 방향입니다.

### 3.2 시각화 및 검증

* 이변량 데이터 실습: 2차원 데이터를 LDA 축으로 투영한 결과, 히스토그램 상에서 두 클래스가 겹침 없이 완벽하게 분리되는 것을 확인할 수 있습니다.
* 공분산 구조(데이터의 퍼짐 형태)에 따라 투영 결과가 달라지며, $S_W^{-1}$ 연산을 통해 데이터의 산포를 고려한 보정이 이루어집니다.

## 4. 다중 클래스 LDA로의 확장

클래스가 3개 이상인 경우, 단일 벡터 W가 아닌 행렬 W를 사용하여 데이터를 저차원 공간으로 투영합니다.

* 차원 결정: 일반적으로 (클래스 수 - 1)차원까지 투영할 때 풍부한 분류 정보를 유지할 수 있습니다.
* 행렬 크기 측정(Trace): W가 행렬이 되면 분수 형태의 지표를 직접 정의할 수 없으므로, 행렬의 대각 원소 합인 트레이스(Trace) 연산을 사용합니다.
  * $\frac{Tr(W^T S_B W)}{Tr(W^T S_W W)}$ 를 최대화하는 W를 탐색합니다.
* 고유값 분해(EVD): $S_W^{-1} S_B$ 행렬에 대해 고유값 분해를 수행합니다.
  1. 고유값이 큰 순서대로 고유 벡터($W_1, W_2, \dots$)를 추출합니다.
  2. 추출된 고유 벡터들을 열 벡터로 모아 투영 행렬 W를 구성합니다.
  3. 고유값이 크다는 것은 해당 방향이 클래스 간 분산은 크고 클래스 내 분산은 작은 최적의 분류 방향임을 의미합니다.


--------------------------------------------------------------------------------


## 5. 결론

선형 판별 분석(LDA)은 결정 초평면의 개념을 확장하여, 데이터의 통계적 특성(평균과 분산)을 활용해 최적의 분류 축을 찾아내는 기법입니다. 이진 분류에서는 $S_W^{-1}(M_2 - M_1)$ 방향으로의 투영을 통해, 다중 클래스에서는 고유값 분해를 통한 저차원 프로젝션을 통해 데이터의 분류 성능을 극대화합니다. 이는 단순한 차원 축소와 달리, 클래스 간 정보를 보존하면서도 데이터의 복잡성을 줄이는 데 강력한 통찰을 제공합니다.
