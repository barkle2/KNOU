# 커널 기법

## 1. 핵심 요약 (Executive Summary)

* 희소 솔루션(Sparse Solution)의 추구: SVM은 전체 트레이닝 데이터 중 결정 경계 형성에 핵심적인 '서포트 벡터'만을 선별하여 모델을 구성함으로써 계산 효율성과 일반화 성능을 동시에 확보합니다.
* 마진 최대화(Margin Maximization): 결정 초평면과 가장 가까운 데이터 포인트 사이의 거리인 마진을 최대화하여 이상치에 대한 강건성을 높이고 예측의 안정성을 도모합니다.
* 커널 트릭(Kernel Trick)의 활용: 고차원 피처 공간으로의 명시적 매핑 없이도 커널 함수를 통한 내적 연산만으로 복잡한 비선형 결정 경계를 학습할 수 있습니다.
* KKT 조건을 통한 최적화: 2차 최적화 문제(QP)를 해결하기 위해 라그랑주 승수법을 적용하며, KKT 조건을 만족함으로써 프라이멀 문제와 듀얼 문제의 최적해가 일치하는 스트롱 듀얼리티(Strong Duality)를 이용합니다.


--------------------------------------------------------------------------------


## 2. 서포트 벡터 분류의 기초 개념

### 2.1 희소 커널 머신 (Sparse Kernel Machines)

희소 커널 머신은 모든 학습 데이터를 사용하는 대신, 예측 시 필요한 데이터 포인트만을 유지하는 모델입니다.

* 목표: 많은 데이터 중 결정 경계에 직접적인 영향을 주는 적은 수의 데이터(희소한 해)를 찾는 것입니다.
* 장점: 예측 연산량이 줄어들고, 불필요한 노이즈를 배제하여 일반화 성능이 향상됩니다.

### 2.2 결정 함수와 유사도 측정

새로운 입력 x에 대한 예측값 y(x)는 다음과 같이 계산됩니다.

* 가중합 구조: 학습 데이터 $x_n$과 새로운 데이터 x 사이의 커널 함수(유사도) 값을 계수 $C_n$으로 가중합하고 바이어스 b를 더합니다.
* 선형 분리 가능성(Linearly Separable): 데이터가 선형적으로 나뉠 수 있다는 가정하에, 레이블이 +1인 경우 결과가 0보다 크고, -1인 경우 0보다 작게 만드는 파라미터 w와 b를 찾습니다.


--------------------------------------------------------------------------------


## 3. 마진(Margin)과 캐논니컬 표현

### 3.1 분리 마진(Separation Margin)의 정의

* 마진(Margin): 분류 초평면과 이 초평면에 가장 가까운 데이터 포인트(서포트 벡터) 사이의 최소 거리입니다.
* 서포트 벡터(Support Vector): 결정 경계(점선)를 지지하고 있는 데이터 포인트들입니다.

### 3.2 캐논니컬 표현(Canonical Representation)

데이터 포인트 x_n과 레이블 t_n에 대하여, 서포트 벡터 지점에서의 결정 함수 출력이 정확히 +1 또는 -1이 되도록 스케일링하는 방식입니다.

* 제약 조건: $t_n(w^T \phi(x_n) + b) \ge 1$ (서포트 벡터일 때 등호 성립)
* 마진 수식: 마진 $\rho$는 $\frac{1}{\|w\|}$로 정의되며, 이는 w의 크기가 작을수록 마진이 넓어짐을 의미합니다.

### 3.3 마진 최대화의 이점

1. 일반화 성능 향상: 마진이 넓을수록 새로운 데이터가 경계를 잘못 넘을 가능성이 줄어듭니다.
2. 강건성(Robustness): 마진이 넓으면 이상치가 결정 경계를 크게 흔들지 못하도록 방어할 수 있습니다.


--------------------------------------------------------------------------------


## 4. 최적화 전략: KKT 조건과 듀얼 문제

### 4.1 QP(Quadratic Programming) 문제로의 전환

마진을 최대화하는 것은 $\frac{1}{2}\|w\|^2$을 최소화하는 것과 같으며, 이는 부등식 제약 조건을 가진 2차 최적화 문제입니다.

### 4.2 KKT(Karush-Kuhn-Tucker) 조건

최적해에 도달하기 위해 만족해야 하는 네 가지 필수 조건입니다.

1. 스테이셔너리티(Stationarity): 라그랑주 함수를 w와 b로 미분한 값이 0이어야 함.
2. 프라이멀 타당성(Primal Feasibility): 원래의 부등식 제약 조건을 충족해야 함.
3. 듀얼 타당성(Dual Feasibility): 라그랑주 승수 $\alpha_n$이 0 이상이어야 함.
4. 상보적 상성(Complementary Slackness): $\alpha_n$과 제약 조건식의 곱이 0이어야 함. 이는 $\alpha_n > 0$인 데이터만이 서포트 벡터가 됨을 보장하여 희소성을 구현합니다.

### 4.3 프라이멀과 듀얼의 관계

* 듀얼 문제(Dual Problem): 프라이멀 변수 w, b를 제거하고 라그랑주 승수 $\alpha$에 대해 정리한 문제로, 이를 최대화함으로써 최적해를 구합니다.
* 스트롱 듀얼리티(Strong Duality): 선형 제약을 가진 QP 문제에서는 프라이멀의 최소값과 듀얼의 최대값이 일치합니다.


--------------------------------------------------------------------------------


## 5. 커널 트릭(Kernel Trick)과 주요 커널

### 5.1 커널 트릭의 핵심

고차원 특징 공간 매핑 함수 $\phi(x)$를 직접 계산하는 대신, 두 데이터의 내적값 $\phi(x_n)^T \phi(x_m)$을 반환하는 커널 함수 $k(x_n, x_m)$를 사용합니다. 이를 통해 무한 차원의 연산도 가능해집니다.

### 5.2 머서 정리(Mercer's Theorem)

어떤 함수가 유효한 커널이 되기 위해서는 대칭성(Symmetry)과 양의 준정부호(Positive Semi-definite) 조건을 만족해야 합니다.

### 5.3 주요 커널 함수의 특징

|커널 종류|수식/특징|주요 하이퍼 파라미터|
|---|---|---|
|RBF (가우시안)|두 점 사이의 거리 제곱에 기반한 유사도 측정|감마($\gamma$) 또는 시그마($\sigma$)|
|폴리노미얼|입력 벡터 내적에 상수를 더한 뒤 d차 거듭제곱|다항식의 차수(d), 상수(c)|
|시그모이드|신경망의 활성화 함수와 유사한 형태|파라미터 $\alpha$, $r$ (머서 조건 주의)|

## 6. 파이썬 실습 및 구현 요약

하드 마진 SVM의 학습 프로세스는 scipy.optimize.minimize 함수를 활용하여 구현할 수 있습니다.

1. 커널 행렬(K) 생성: 모든 데이터 쌍 (x_i, x_j)에 대해 커널 값을 계산하여 N \times N 행렬을 구성합니다.
2. 듀얼 목적 함수 정의: 최적화 변수 $\alpha$에 대해 W(\alpha)를 계산하는 함수를 만듭니다. (최대화를 위해 부호를 반전시켜 미니마이즈 함수에 전달)
3. 제약 조건 설정:
  * $\alpha_n \ge 0$ (Bounds 설정)
  * $\sum \alpha_n t_n = 0$ (Equality Constraint 설정)
4. 최적화 수행: 초기값 0에서 출발하여 최적의 $\alpha$ 값을 도출합니다.
5. 바이어스(b) 계산: KKT 조건을 이용하여 서포트 벡터로부터 최적의 바이어스를 산출합니다.
6. 결정 경계 시각화: 매시 그리드(Mesh Grid)를 생성하고 학습된 모델로 영역을 분류하여 시각적으로 확인합니다.


--------------------------------------------------------------------------------


결론: 서포트 벡터 머신은 마진 최대화와 커널 트릭을 결합하여 고차원의 복잡한 비선형 분류 문제를 효율적으로 해결하는 모델입니다. 특히 KKT 조건을 통한 듀얼 문제 해결 방식은 모델의 희소성을 보장하며 강력한 수치 최적화 기반을 제공합니다.
