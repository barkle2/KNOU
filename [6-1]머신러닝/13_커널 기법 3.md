# 커널 기법 3: SVDD 및 One-Class SVM 분석

## 핵심요약 (Executive Summary)

* 원클래스 문제의 핵심: 정상 데이터만을 학습하여 비정상 데이터(이상치)를 구분해내는 문제로, 생산 라인의 불량품 탐지 등 비정상 데이터가 극히 드문 상황에서 유효하다.
* SVDD (서포트 벡터 데이터 디스크립션): 정상 데이터를 감싸는 '최소 크기의 초구(Hypersphere)'를 찾는 방식이다. 구의 중심과 반지름을 최적화하며, 구 밖에 위치한 데이터를 이상치로 판별한다.
* 원클래스 SVM: 데이터를 원점으로부터 최대한 멀리 떨어뜨리는 '초평면(Hyperplane)'을 학습한다. 초평면과 원점 사이의 마진을 최대화하여 정상 영역을 정의하며, 마진 너머의 데이터를 비정상으로 간주한다.
* 커널 트릭의 활용: 두 모델 모두 커널 트릭을 통해 데이터를 고차원 공간으로 매핑함으로써, 복잡한 비선형 패턴을 가진 데이터도 효과적으로 처리할 수 있다.
* 성능 평가의 다각화: 데이터 불균형이 심한 원클래스 문제 특성상 '정확도(Accuracy)'는 신뢰하기 어렵다. 따라서 민감도, 특이도, 양성 예측도(PPV), 음성 예측도(NPV)의 네 가지 지표를 동시에 고려해야 한다.


--------------------------------------------------------------------------------


## 1. 원클래스 문제 (One-Class Problem)의 이해

원클래스 문제는 데이터셋에 오직 한 클래스(정상 데이터)의 샘플만 존재하거나, 비정상 데이터(이상치)가 거의 없는 상황을 다룬다.

* 정의: 정상 데이터를 학습하여 해당 분포의 경계를 설정하고, 이 경계를 벗어나는 모든 객체를 비정상 데이터로 구분하는 문제다.
* 가정: 관찰된 데이터는 모두 정상이며, 이상치는 존재하지 않거나 극소수라고 가정한다.
* 목표: 정상 데이터의 분포 특성을 가장 잘 설명하는 모델을 구축하여 미지의 이상치를 탐지하는 것이다.


--------------------------------------------------------------------------------


## 2. 서포트 벡터 데이터 디스크립션 (SVDD)

SVDD는 데이터를 서포트 벡터로 설명하며, 정상 데이터를 포함하는 최소한의 부피를 가진 구(Sphere)를 정의하는 모델이다.

### 2.1 기본 원리와 결정 함수

* 최적화 목표: 대부분의 정상 데이터를 포함하면서 반지름 R이 최소가 되는 초구를 찾는 것이다.
* 구성 요소:
  * 중심 (a): 데이터의 분포를 가장 잘 대표하는 지점이다.
  * 반지름 (R): 구의 크기를 결정하며, 작을수록 데이터를 더 타이트하게 감싼다.
* 결정 함수 (Decision Function): 데이터 x와 중심 a 사이의 거리를 계산하여 반지름 R과 비교한다.
  * $f(x) = \|x - a\|^2 - R^2$
  * 결과값이 0 이하이면 정상, 0보다 크면 이상치로 판별한다.

### 2.2 최적화 및 소프트 마진 (Soft Margin)

실제 데이터에는 노이즈나 예외가 존재할 수 있으므로, 제약 조건을 완화하기 위해 '슬랙 변수($\xi$)'를 도입한 소프트 마진 SVDD가 주로 사용된다.

* 프라이멀 문제 (Primal Problem): 반지름 R을 최소화하는 동시에 슬랙 변수의 합에 페널티를 부여한다. 이때 하이퍼파라미터 C는 슬랙 변수의 영향력(데이터를 구 안에 포함하려는 엄격함)을 조절한다.
* 듀얼 문제 (Dual Problem): 라그랑주 승수($\alpha$)를 사용하여 최적화하며, 모든 $\alpha$의 합은 1이어야 하고 각 $\alpha$는 0과 C 사이의 값을 가진다.
* 결과 도출: 중심 a는 데이터 점들의 가중 평균으로 계산되며, 반지름 R은 서포트 벡터와 중심 간의 거리를 통해 결정된다.

## 3. 원클래스 SVM (One-Class SVM)

원클래스 SVM은 기존 SVM이 두 클래스를 분리하는 것과 달리, 단일 클래스 데이터를 원점(Origin)으로부터 분리하는 초평면을 찾는 방식이다.

### 3.1 기본 원리 및 결정 함수

* 최적화 목표: 데이터가 원점에서 최대한 멀어지도록 하는 초평면을 찾고, 원점과 초평면 사이의 간격(마진, $\rho$)을 최대화한다.
* 구성 요소:
  * 방향 벡터 (w): 매핑된 공간에서의 초평면 방향을 정의한다.
  * 마진 ($\rho$): 원점과 데이터 간의 최대 간격을 나타낸다.
* 결정 함수: 데이터와 초평면 사이의 관계를 평가한다.
  * 함수값이 0보다 크면 정상, 0보다 작으면 비정상 영역으로 평가한다. (※ 실습 시 성능 지표의 일관성을 위해 부호를 반전시키기도 한다.)

### 3.2 하이퍼파라미터 $\nu$ (Nu)

* 원클래스 SVM에서 $\nu$는 0과 1 사이의 값을 가지며, 이상치 비율의 상한선이자 서포트 벡터 비율의 하한선을 조절하는 핵심 파라미터다.
* $\nu$는 라그랑주 승수 $\alpha$의 상한선을 결정하는 역할도 수행한다 ($0 \le \alpha_i \le \frac{1}{\nu n}$).

## 4. 커널 확장 (Kernel Expansion)

SVDD와 원클래스 SVM 모두 선형적으로 분리되지 않는 복잡한 패턴의 데이터를 처리하기 위해 커널 트릭을 사용한다.

* 메커니즘: 입력 공간의 데이터를 고차원 특징 공간(Feature Map)으로 매핑하여, 그곳에서 초구(SVDD)나 초평면(OCSVM)을 형성한다.
* 이점: 복잡한 경계를 가진 데이터셋에서도 유연한 결정 경계를 생성할 수 있다. 주로 RBF(Radial Basis Function) 커널이 사용된다.

## 5. 분류 성능 평가 지표

원클래스 문제에서는 대다수의 데이터가 정상이므로, 단순히 모델이 모두를 정상으로 예측해도 정확도가 높게 나오는 '정확도의 역설'이 발생한다. 따라서 다음 네 가지 지표를 종합적으로 검토해야 한다.

### 5.1 네 가지 핵심 지표 분석

|지표명|정의|의미 (진단 기기 비유)|
|---|---|---|
|민감도 (Sensitivity)|실제 이상치 중 모델이 이상치로 맞게 예측한 비율|질병이 있는 사람을 질병으로 판단할 확률|
|특이도 (Specificity)|실제 정상 중 모델이 정상으로 맞게 예측한 비율|건강한 사람을 건강하다고 판단할 확률|
|양성 예측도 (PPV)|모델이 이상치라고 한 것 중 실제 이상치의 비율|'양성' 판정을 받은 사람이 실제 환자일 확률|
|음성 예측도 (NPV)|모델이 정상이라고 한 것 중 실제 정상의 비율|'음성' 판정을 받은 사람이 실제 건강할 확률|

### 5.2 지표 해석의 관점

* 민감도와 특이도: 모델 자체의 탐지 성능을 나타내는 '신의 관점'에서의 수치다.
* 예측도 (PPV/NPV): 모델의 결과에 의존해야 하는 사용자의 입장에서 결과의 신뢰성을 나타내는 '인간의 관점'에서의 수치다.
* 종합적 고려: 단일 지표에만 의존할 경우 데이터 구성(불균형 정도)에 따른 수치적 착시가 발생할 수 있으므로, 모든 지표를 동시에 분석하여 모델의 타당성을 검증해야 한다.
