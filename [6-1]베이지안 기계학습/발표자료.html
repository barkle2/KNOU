1. 연구 동기 — 왜 베이지안 신경망인가?

  • 일반 신경망은 손실을 최소화하는 하나의 가중치만 찾음 (MLE, 점추정)
  • → "얼마나 확신하는지"를 표현하지 못함
  • BNN은 가중치 w 에 사전분포를 부여하고 사후분포 p(w│D)를 추론
  • → 예측과 불확실성을 동시에 정량화 (베이지안 모델 평균)

점추정 (일반 NN)

w = 단일 값 → 예측선 1개, 신뢰도 없음

분포추정 (BNN)

w ~ 분포 → 예측선의 띠(구간), 불확실성 정량화

2. 분석 대상 — 임금의 역U자 프로파일

  • 노동경제학의 전형: 임금은 경력(연령)에 따라 상승 후 정점·완만해지는 역U자
  • 선형모형으로 포착 불가 → 신경망이 자동 학습하기 적합
  • 표본은 중년층에 집중, 청년·고령층은 희박
  • → 연령 구간별 불확실성을 보여주기 이상적인 사례
3,000표본 수 (명)
age → wage단일 변수 비선형 회귀
80 / 20학습 / 검증 분할

3. 탐색적 분석 (1) — 다관점 산점도

연령·연도·학력·직군·건강보험 등 여러 관점에서 본 임금 — 연령에 따른 비선형 상승과 임금의 이질성이 관찰된다.

3. 탐색적 분석 (2) — 역U자와 표본 희박성

(중) 연령대별 평균임금은 18세 76 → 40대 119 정점 → 60대 이후 감소하는 역U자. (우) 표본은 중년층에 집중, 양 끝은 희박 — 이후 불확실성 분석의 핵심 배경.

4. 방법론 — BNN 모형과 변분추론(SVI)

모형

yi ~ 𝒩( fw(xi), σ² )
fw(x) = w₃ᵀ · tanh( W₂ · tanh(w₁x + b₁) + b₂ ) + b₃

은닉층 2개(각 16유닛, tanh) · 가중치 사전분포 w ~ 𝒩(0, s²) · σ ~ HalfNormal(1)

추론 — SVI

  • 사후분포는 직접 계산 불가 → 변분분포 qλ로 근사
  • 증거하한(ELBO)을 최대화
  • 구현: NumPyro (AutoNormal + Adam)
  • 20,000 step 최적화

5. 학습 수렴 — ELBO

  • ELBO가 −6,666 → −3,429로 증가
  • 안정적으로 수렴 — 코드 정합성·최적화 건전성 확인
  • 수렴한 변분분포로부터 사후예측 1,000개 샘플 생성
≈ −3,429수렴한 ELBO (증거하한 증가·안정)

6. 핵심 결과 — 불확실성의 연령별 구조

(a) BNN 사후평균은 역U자를 재현. (b) 95% 신용구간(평균함수)과 예측구간(잡음 포함)이 데이터가 희박한 청년·고령 구간에서 넓어진다 — "모르는 곳에서 모른다고 말하는" 추론.

  • 정확도는 비슷 — 연령 단독으로 설명되는 변동이 제한적(임금의 이봉구조). BNN의 가치는 불확실성 표현에 있다.
  • 한계: 단일 정규 가능도로 이봉구조 포착 불가 → 공변량 추가·이분산·혼합밀도로 확장 가능

8. 결론

  • 연령–임금 비선형 회귀에서 세 모형의 평균 예측은 유사했으나, 불확실성 표현에서 결정적 차이
  • BNN은 데이터가 풍부한 중년층에서 좁고, 희박한 청년·고령층에서 넓은 신용구간을 자동 부여
  • 예측의 신뢰도를 정량화해야 하는 실무(정책·의사결정)에서 베이지안 접근의 본질적 이점
