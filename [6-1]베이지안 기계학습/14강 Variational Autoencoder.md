# 14강 Variational Autoencoder

본 문서는 베이지안 기계 학습 강의 내용을 바탕으로, 차원 축소의 핵심 개념인 주성분 분석(PCA)부터 오토인코더(Autoencoder), 그리고 확률적 생성 모형인 베리에이셔널 오토인코더(Variational Autoencoder, VAE)의 원리와 응용을 종합적으로 정리한 브리핑 문서이다.


--------------------------------------------------------------------------------


## 1. 핵심 요약 (Executive Summary)

차원 축소(Dimension Reduction)는 고차원 데이터의 핵심 특성을 추출하여 저차원 공간으로 변환하는 기법으로, 데이터 시각화와 전처리에 필수적이다. 가장 기본적인 선형 기법인 **주성분 분석(PCA)**은 데이터의 분산을 최대화하거나 재구성 오차(Reconstruction Error)를 최소화하는 방향을 찾는다. 이를 신경망을 이용한 비선형 매핑으로 확장한 것이 **오토인코더(AE)**이며, 여기서 더 나아가 확률 분포를 도입하여 새로운 데이터를 생성할 수 있도록 설계된 모형이 **베리에이셔널 오토인코더(VAE)**이다. VAE는 단순한 차원 축소를 넘어, 잠재 변수(Latent Variable)의 사후 분포를 추론함으로써 데이터 생성 및 결측치 보간 등 무궁무진한 활용 가능성을 제공하는 생성 모형(Generative Model)으로서 핵심적인 가치를 지닌다.


--------------------------------------------------------------------------------


## 2. 차원 축소와 주성분 분석 (PCA)

### 2.1 차원 축소의 정의와 필요성

차원 축소는 고차원 공간(특성/변수가 많은 공간)의 데이터를 정보 손실을 최소화하면서 저차원 공간으로 줄이는 과정이다.

* 시각화: 데이터의 특성을 추출하여 인간이 이해할 수 있는 형태로 표현한다.
* 전처리: 분류(Classification) 등 다른 학습 알고리즘의 효율성을 높이는 단계로 활용된다.

### 2.2 주성분 분석 (PCA)의 원리

PCA는 가장 단순하고 널리 사용되는 차원 축소 기법으로, **선형적이며 직교하는 프로젝션(Linear and Orthogonal Projection)**을 찾는 것이 핵심이다.

* 접근 방식:
  1. 재구성 오차 최소화: 고차원 데이터 X와 저차원 근사치 Z 사이의 거리를 최소화하는 계수 행렬 W를 구한다.
  2. 분산 최대화: 프로젝션된 데이터의 분산이 최대가 되는 방향을 찾는다.
  * 두 방식은 결과적으로 동일한 솔루션을 제공하며, 공분산 행렬의 고유값(Eigenvalue) 크기순으로 나열된 고유벡터(Eigenvector)들이 주성분이 된다.
* 한계: 데이터의 복잡한 비선형 구조를 반영하는 데 제약이 있다.


--------------------------------------------------------------------------------


## 3. 오토인코더 (Autoencoder)

### 3.1 비선형 확장

오토인코더는 PCA의 선형 가정을 깨고, 신경망(Neural Network)을 활용해 **비선형 매핑(Non-linear Mapping)**을 수행한다.

* 인코더(Encoder): 고차원 데이터 X를 저차원 잠재 변수 Z로 변환한다. (FE)
* 디코더(Decoder): 잠재 변수 Z를 다시 원래의 고차원 데이터 $\hat{X}$로 복원한다. (FD)
* 목표: 재구성 오차 $||X - FD(FE(X))||^2$를 최소화하는 가중치를 학습한다.

### 3.2 퇴화 해(Degenerate Solution) 방지 기법

단순히 데이터를 복사하는 문제를 막기 위해 다음과 같은 제약 조건을 사용한다.

|기법|설명|
|----|------|
|바틀렉(Bottleneck)|히든 레이어(잠재 변수)의 개수를 입력 차원보다 현저히 줄여 핵심 특성만 학습 유도|
|디노이징(Denoising)|입력 데이터에 임의의 노이즈를 주입하고 원래의 깨끗한 입력을 복구하도록 학습|
|스파스(Sparse)|히든 유닛의 활성화 함수에 희소성(Sparsity) 제약을 부여|
|컨트랙티브(Contractive)|히든 유닛의 미분값에 페널티를 주어 급격한 변화를 억제


--------------------------------------------------------------------------------


## 4. 베리에이셔널 오토인코더 (VAE)

### 4.1 확률적 버전으로의 진화

VAE는 오토인코더에 확률론적 관점을 도입한 모형이다. 잠재 변수 Z를 고정된 값이 아닌 확률 분포로 취급한다.

* 생성 모형(Generative Model): 입력 데이터와 유사한 특성을 가진 새로운 샘플을 생성할 수 있다.
* 구조:
  * 잠재 변수 분포: 일반적으로 가우시안(Gaussian) 분포를 가정한다.
  * 조건부 분포: Z가 주어졌을 때 X의 분포는 가우시안 또는 베르누이(Bernoulli) 분포를 사용한다.
  * 변분 추론(Variational Inference): 사후 분포 p(z|x)를 직접 구하기 어렵기 때문에, 이를 근사하는 변분 분포(인코더 뉴럴 네트워크)를 정의하여 학습한다.

### 4.2 AE와 VAE의 차이점

* 오토인코더(AE): 결정론적(Deterministic) 모델로, 랜덤한 입력이 들어오면 성능이 급격히 저하되며 새로운 데이터를 생성하는 기능이 부족하다.
* VAE: 확률적(Probabilistic) 모델로, 잠재 공간의 분포로부터 샘플링을 통해 원본과 닮은 새로운 데이터를 생성할 수 있다.


--------------------------------------------------------------------------------


## 5. 생성 모형의 특징 및 응용

### 5.1 생성 모형의 정의

결합 확률 분포 p(x, z)를 학습하여 데이터의 밀도(Density)를 추정하고, 이 분포로부터 새로운 관측치를 생성하는 모델이다. VAE 외에도 GAN(Generative Adversarial Networks), 디퓨전(Diffusion) 모델 등이 존재한다.

### 5.2 주요 활용 분야

* 밀도 추정(Density Estimation): 입력 데이터의 특성이 어디에 집중되어 있는지 파악한다.
* 결측치 보간(Imputation): 유실된 데이터(Missing Value)를 기존 데이터의 특성을 바탕으로 채워 넣는다.
* 잠재 공간 보간(Latent Space Interpolation): 이미지의 가려진 부분을 채우거나, 특정 위치의 자료가 없을 때 주변 데이터를 활용해 보간한다.


--------------------------------------------------------------------------------


## 6. Pyro를 이용한 VAE 구현 (MNIST 예제)

강의에서는 파이토치(PyTorch) 기반의 확률적 프로그래밍 라이브러리인 Pyro를 활용하여 손글씨 숫자 데이터(MNIST)를 분류 및 생성하는 단계를 제시한다.

1. 데이터 로드: MNIST 손글씨 이미지 데이터셋을 다운로드하고 전처리한다.
2. 디코더 정의: 잠재 변수로부터 이미지를 복원하는 뉴럴 네트워크 클래스를 생성한다. (출력층에 시그모이드 활성화 함수 사용)
3. 인코더 정의: 이미지로부터 잠재 변수의 평균과 분산을 계산하는 뉴럴 네트워크 클래스를 생성한다.
4. 모델(Model) 정의: 잠재 변수의 사전 분포(Prior)와 데이터의 우도(Likelihood)를 정의한다.
5. 가이드(Guide) 정의: 사후 분포를 근사하는 변분 분포를 정의하며, 인코더 네트워크를 활용한다.
6. 학습(Training): 반복문을 통해 재구성 오차와 분포 간의 차이를 최적화하며 가중치를 학습한다.
7. 평가: 테스트 데이터를 활용하여 학습된 모델의 손실(Loss)을 확인하고 생성 성능을 검증한다.
