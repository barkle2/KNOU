# 미분의 개념과 기본 원리: 데이터 과학을 위한 수학적 기초

이 문서는 데이터 과학의 핵심 기반이 되는 미분의 개념, 계산 원리, 그리고 다변수 함수로의 확장 및 통계적 적용 사례를 체계적으로 정리한 브리핑 문서이다.

## 핵심 요약 (Executive Summary)

본 문서는 함수의 연속성에서 나아가 미분의 정의와 기하학적 의미를 심도 있게 다룬다. 주요 내용은 다음과 같다:

* 미분의 정의: 평균 변화율에서 시작하여 극한을 통해 도함수를 정의하며, 이는 기하학적으로 접선의 기울기를 의미한다.
* 미분 가능성과 연속성: 미분이 가능하기 위해서는 반드시 해당 점에서 연속이어야 하나, 연속 함수라고 해서 모두 미분이 가능한 것은 아니다(예: 절댓값 함수의 꺾인 점).
* 미분 공식: 다항함수, 지수·로그 함수, 합성 함수 등 다양한 형태의 함수에 대한 미분 계산법을 확립한다.
* 다변수 함수와 편미분: 여러 변수를 가진 함수에서 특정 변수만을 기준으로 미분하는 편미분의 개념을 정의하고, 이를 통해 변화율을 분석한다.
* 통계적 적용: 정규 분포를 따르는 데이터의 파라미터(평균, 분산)를 추정하기 위한 최대 우도 추정(MLE) 과정에서 로그 우도 함수의 편미분이 어떻게 활용되는지 실무적 사례를 제시한다.

## 1. 미분의 정의와 기하학적 의미

### 1.1 변화율의 개념

* 평균 변화율: x의 변화량(\Delta x = h)에 대한 y의 변화량(\Delta y)의 비율이다.
  * 공식: \frac{f(x_0 + h) - f(x_0)}{h}
  * 의미: 함수 위의 두 점을 잇는 직선의 기울기이다.
* 순간 변화율: 평균 변화율에서 h가 0에 한없이 가까워질 때의 극한값이다.
  * 의미: 특정 점에서의 즉각적인 변화를 나타내며, 기하학적으로는 그 점에서의 접선의 기울기와 같다.

### 1.2 도함수 (Derivative Function)

함수 f(x)의 정의역 내 모든 점에서의 미분 계수를 함수로 나타낸 것이다.

* 정의식: f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}
* 표기법: f'(x), \frac{dy}{dx}, \frac{d}{dx}f(x) 등으로 표현한다.
* 사례: 선형 회귀 분석식 y = \beta_0 + \beta_1x + \epsilon을 미분하면 \frac{dy}{dx} = \beta_1이 되며, 이는 독립 변수가 1 증가할 때 종속 변수의 변화율을 의미한다.

## 2. 미분 가능성과 연속성의 관계

함수가 특정 점 x_0에서 미분 가능하기 위해서는 해당 점에서의 미분 계수(극한값)가 존재해야 한다.

* 필요조건: 미분 가능하려면 반드시 연속이어야 한다. 분모 h가 0으로 갈 때 극한값이 존재하기 위해서는 분자도 0으로 수렴해야 하기 때문이다.
* 미분 불가능한 경우:
  1. 불연속 함수: 점이 끊겨 있는 경우 미분이 불가능하다.
  2. 첨점(뾰족한 점): 함수가 연속이더라도 급격하게 꺾이는 점(예: f(x) = |x|의 x=0 지점)에서는 접선의 기울기가 하나로 정의되지 않아 미분이 불가능하다.

| 구분 | 연속성 여부 | 미분 가능 여부 | 비고 |
| --- | --- | --- | --- |
| f(x) = x^2 | O | O | 부드럽게 연결됨 |
| $g(x) = \| x \| $ | O |  |
| $h(x) = \frac{x^2}{ \| x \| }$ | X |  |

| 함수 유형 | 함수식 | 도함수 |
| --- | --- | --- |
| 거듭제곱 | x^n | n \cdot x^{n-1} |
| 지수 함수 (자연상수) | e^x | e^x |
| 지수 함수 (일반상수) | a^x | \ln a \cdot a^x |

| 합성 함수 | f(g(x)) | f'(g(x)) \cdot g'(x) |

## 4. 다변수 함수와 편미분

변수가 여러 개인 다변수 함수에서는 어떤 변수를 기준으로 변화율을 측정할 것인지가 중요하다.

### 4.1 다변수 함수의 극한과 연속

* 극한: 두 점 사이의 거리가 델타(\delta) 미만일 때 함수값과 극한값 사이의 거리가 엡실론(\epsilon)보다 작아지게 하는 델타가 존재하면 극한이 존재한다고 정의한다.
* 연속: 함수값과 극한값이 존재하고 그 두 값이 같아야 한다.

### 4.2 편미분 (Partial Differentiation)

특정 변수를 제외한 나머지 변수를 상수처럼 취급하여 미분하는 방식이다.

* x에 대한 편도함수 (\frac{\partial f}{\partial x}): y를 상수로 보고 x에 대해 미분한다.
* y에 대한 편도함수 (\frac{\partial f}{\partial y}): x를 상수로 보고 y에 대해 미분한다.

## 5. 통계적 적용 사례: 정규 분포의 로그 우도 함수 분석

데이터 과학에서 미분은 파라미터 최적화에 필수적이다. 정규 분포를 따르는 n개의 데이터 관측값이 있을 때, 평균(\mu)과 분산(\sigma^2)을 추정하기 위해 로그 우도 함수를 활용한다.

### 5.1 로그 우도 함수 (Log-Likelihood Function)

우도 함수는 개별 데이터 우도의 곱으로 표현되므로, 계산의 편의를 위해 로그를 취해 합의 형태로 변환한다. 이 함수는 \mu와 \sigma^2를 변수로 갖는 이변수 함수가 된다.

### 5.2 편도함수 계산 결과

1. 평균(\mu)에 대한 편미분: \frac{\partial \ln L}{\partial \mu} = \frac{1}{\sigma^2} \sum_{i=1}^{n} (x_i - \mu)
   * 특징: 원래 함수가 \mu에 대한 2차식 형태이므로 미분 시 1차 함수(직선)가 된다.
2. 분산(\sigma^2)에 대한 편미분: \frac{\partial \ln L}{\partial \sigma^2} = -\frac{n}{2\sigma^2} + \frac{1}{2(\sigma^2)^2} \sum_{i=1}^{n} (x_i - \mu)^2
   * 특징: \sigma^2가 증가함에 따라 급격히 감소하다가 완만하게 증가하는 분수 함수 형태를 띤다.

### 5.3 시각화 분석 요약

* 로그 우도 함수: 3차원 공간에서 \mu 고정 시와 \sigma^2 고정 시 각각 다른 곡선 형태의 단면을 가진다.
* 최적화: 편도함수 값이 0이 되는 지점을 찾음으로써 우도 함수를 최대화하는 최적의 파라미터를 결정할 수 있다.
