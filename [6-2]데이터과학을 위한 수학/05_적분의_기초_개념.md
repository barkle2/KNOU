# 제5강 적분의 기초 개념

## 핵심 요약 (Executive Summary)

본 문서에서는 데이터 과학의 수학적 기초가 되는 적분의 핵심 개념과 주요 계산 기법(치환 적분, 부분 적분), 그리고 이를 확률 밀도 함수(PDF)에 적용하는 방법론을 종합적으로 설명합니다. 주요 핵심 내용은 다음과 같습니다.

* **적분의 본질과 리만합:** 정적분은 곡선 아래의 면적을 구하는 개념으로, 구간을 n개의 소구간으로 쪼개 직사각형 넓이의 합을 구한 뒤 무한대로 극한을 보내는 **리만합의 극한(Limit of Riemann Sum)**으로 정의됩니다.
* **적분 가능성의 조건:** 연속함수는 항상 적분 가능합니다. 미분 불가능한 점(예: 꺾인 점)이나 유한개의 불연속점이 존재하는 함수(예: 계단 함수)라 하더라도 적분이 가능하지만, 모든 점에서 불연속인 디리클레 함수(Dirichlet function)는 리만 적분이 불가능합니다.
* **미적분의 기본 정리:** 미분과 적분은 역연산 관계에 있습니다. 도함수를 정적분한 값은 원래 함수의 변화량과 같으며, 정적분으로 정의된 함수를 미분하면 원래의 피적분함수가 유도됩니다.
* 적분 기법의 체계화:
  * **치환 적분법(Substitution):** 합성함수의 미분법 역과정으로, 복잡한 변수를 u로 치환하여 정형화된 적분 형태로 변환합니다.
  * **부분 적분법(Integration by Parts):** 곱의 미분법 역과정으로, $\int u v' dx = uv - \int u' v dx$ 공식을 이용하여 곱 형태의 함수를 단순화합니다.
* 확률 통계학적 응용:
  * **확률 밀도 함수(PDF)**의 전체 구간 적분값은 항상 1이며, 특정 구간 [a, b]의 정적분값은 해당 사건이 발생할 확률을 의미합니다. 연속형 확률 변수의 단일 점에 대한 확률은 0입니다.
  * **분위수 함수(Quantile Function)**는 누적 확률 분포 함수(CDF)의 역함수로 정의되며, 비감소 특성을 고려해 하한(Infimum) 개념을 사용하여 $F^{-1}(q) = \inf \{x \mid F(x) \ge q\}$로 정밀하게 정의됩니다.
  * 주요 연속형 분포의 적분 결과:
    * **균등 분포 U(a, b):** 평균 $E[X] = \frac{a+b}{2}$, 분산 $Var(X) = \frac{(b-a)^2}{12}$
    * **지수 분포 Exp($\lambda$):** 부분 적분을 적용하여 산출하며, 평균 $E[X] = \frac{1}{\lambda}$, 분산 $Var(X) = \frac{1}{\lambda^2}$

## 1. 적분의 기본 개념 및 수학적 구조

### 1.1 정적분과 리만합 (Definite Integral & Riemann Sum)

닫힌구간 [a, b]에서 음이 아닌 연속함수 $f(x)$가 주어졌을 때, 곡선 아래의 면적을 구하는 과정은 다음과 같이 정의됩니다.

1. 구간 분할: 구간 [a, b]를 $a = x_0 < x_1 < \dots < x_n = b$와 같이 n개의 소구간으로 분할(Partition P)합니다.
2. 리만합 형성: 각 소구간 $[x_{k-1}, x_k]$에 속하는 임의의 점 $c_k$를 선택하고, 밑변의 길이 $\Delta x_k = x_k - x_{k-1}$와 높이 $f(c_k)$를 곱한 직사각형 넓이의 합을 구합니다. $\text{리만합 (Riemann Sum)} = \sum_{k=1}^{n} f(c_k) \Delta x_k$
3. 정적분의 정의: 직사각형의 개수 n을 무한대로 보낼 때($n \to \infty$) 리만합의 극한값이 존재하면, 이를 정적분이라 정의합니다. $\int_{a}^{b} f(x) dx = \lim_{n \to \infty} \sum_{k=1}^{n} f(c_k) \Delta x_k$

* **참고:** 함수값이 음수인 경우, 정적분 값도 음수로 산출됩니다.

### 1.2 미분 가능성과 적분 가능성의 비교

함수의 특성에 따른 미분 및 적분 가능 여부는 다음과 같습니다.

| 함수 유형           | 예시 함수 f(x)                                                                                        | 미분 가능성        | 적분 가능성 (리만 적분) | 원인 및 설명                                                                          |
| ------------------- | ----------------------------------------------------------------------------------------------------- | ------------------ | ----------------------- | ------------------------------------------------------------------------------------- |
| 매끄러운 연속함수   | $f(x) = x^2$                                                                                        | 가능               | 가능                    | 전 구간에서 연속이며 부드럽게 연결됨.                                                 |
| 꺾인 연속함수       | $g(x) = \vert x\vert $                                                                                | $x=0$에서 불가능 | 가능                    | $x=0$에서 순간변화율이 일정하지 않아 미분 불가능하나, 연속함수이므로 적분 가능함.   |
| 유한 불연속 함수    | $h(x) = \begin{cases} 1 & (x \ge 0) \\ 0 & (x < 0) \end{cases}$                                     | $x=0$에서 불가능 | 가능                    | $x=0$에서 점프 불연속이 발생하여 미분 불가능하나, 끊어진 구간을 나누어 적분 가능함. |
| 전 구간 불연속 함수 | 디리클레 함수$d(x) = \begin{cases} 1 & (x \in \mathbb{Q}) \\ 0 & (x \notin \mathbb{Q}) \end{cases}$ | 불가능             | 불가능                  | 무수히 많은 불연속점이 존재하여 직사각형의 극한으로 면적을 정의할 수 없음.            |

* **결론:** 리만 적분이 가능하려면 유한개의 불연속점만을 가져야 합니다.

### 1.3 부정적분 (Indefinite Integral)

부정적분은 미분의 역작용으로, 함수 $f(x)$를 도함수로 갖는 원시함수 $F(x)$를 구하는 과정입니다.

$$
\int f(x) dx = F(x) + C \quad (\text{단, } F'(x) = f(x), \, C \text{는 적분상수})
$$

* **상수함수의 미분과 적분상수:** 상수 C를 미분하면 0이 되므로, 부정적분 계산 시에는 반드시 임의의 적분상수 C를 붙여야 합니다.
* 주요 부정적분 공식:
  * **거듭제곱:** $\int x^n dx = \frac{1}{n+1} x^{n+1} + C \quad (n \neq -1)$
  * **지수함수:** $\int e^x dx = e^x + C$
  * **분수함수:** $\int \frac{1}{x} dx = \ln|x| + C$
    * **주의:** $\ln x$의 도함수는 x>0에서만 정의되지만, $y = \frac{1}{x}$은 음수 영역에서도 정의되므로 부정적분 결과에 절댓값을 취해 $\ln|x| + C$로 표현합니다.

### 1.4 미적분의 기본 정리 (Fundamental Theorem of Calculus)

미분과 적분의 상호 역연산 관계를 정립하는 정리입니다.

1. 제1정리: 닫힌구간 [a, b]에서 연속인 함수 $f(t)$에 대해 $F(x) = \int_{a}^{x} f(t) dt$로 정의된 함수 $F(x)$는 미분 가능하며, 그 도함수는 원래 함수와 같습니다. $\frac{d}{dx} \left( \int_{a}^{x} f(t) dt \right) = f(x)$
2. 제2정리 (정적분 계산 정리): 함수 $f(x)$의 한 부정적분을 $F(x)$라 할 때, 정적분 값은 부정적분의 구간 변화량과 같습니다. $\int_{a}^{b} f(x) dx = F(b) - F(a)$

## 2. 복잡한 함수의 적분 기법

### 2.1 치환 적분법 (Integration by Substitution)

합성함수의 미분법에서 유도된 적분법으로, 복잡한 식의 일부를 단일 변수 u로 치환하여 단순화합니다.

* **수학적 원리:** $u = g(x)$로 놓으면 $du = g'(x) dx$가 성립합니다. $\int f(g(x)) g'(x) dx = \int f(u) du = F(u) + C = F(g(x)) + C$
* **계산 예제:** $\int a e^{-ax} dx$ 계산
  1. $u = -ax$로 치환 $\rightarrow \frac{du}{dx} = -a \implies du = -a dx$
  2. 식 변형: $\int a e^{-ax} dx = - \int e^{-ax} (-a dx) = - \int e^u du$
  3. 적분 실행: $-e^u + C = -e^{-ax} + C$

### 2.2 부분 적분법 (Integration by Parts)

두 함수의 곱 형태 피적분함수를 처리하기 위한 적분법으로, 곱의 미분법 역과정에서 유도됩니다.

* **수학적 원리:** $(uv)' = u'v + uv' \implies uv = \int u'v dx + \int uv' dx$; $\int u v' dx = uv - \int u' v dx$
* **피적분함수 설정 기법:** 미분하기 쉬운 함수를 u, 적분하기 쉬운 함수를 v'로 설정합니다. (지수함수 e^x는 미분/적분 시 형태가 유휴하므로 v'로 두기에 적합함).
* **계산 예제:** $\int x e^x dx$ 계산
  1. $u = x \implies u' = 1$
  2. $v' = e^x \implies v = e^x$
  3. 공식 적용: $\int x e^x dx = x e^x - \int 1 \cdot e^x dx = x e^x - e^x + C$

## 3. 확률 밀도 함수 및 확률 분포에서의 적분 응용

### 3.1 누적 확률 분포 함수 (CDF)와 확률 밀도 함수 (PDF)

#### 누적 확률 분포 함수 (CDF: Cumulative Distribution Function)

확률변수 X가 특정 값 x 이하일 확률을 출력하는 함수 $F(x) = P(X \le x)$입니다.

* 주요 성질:
  1. 값의 범위: $0 \le F(x) \le 1, \lim_{x \to -\infty} F(x) = 0, \lim_{x \to \infty} F(x) = 1$
  2. 비감소성 (Non-decreasing): x가 증가하면 사건의 범위가 넓어지므로 확률은 감소하지 않고 유지되거나 증가함.
  3. 우연속성 (Right-continuous): 전 구간 연속일 필요는 없으나, 오른쪽 방향에서의 극한값과 함숫값이 같아야 함 ($\lim_{x \to a^+} F(x) = F(a)$).

#### 확률 밀도 함수 (PDF: Probability Density Function)

연속형 확률변수 X의 분포를 결정하는 함수 $f(x)$로, CDF의 적분 형태로 정의됩니다.

$$
F(x) = \int_{-\infty}^{x} f(t) dt \quad \left( F(x) \text{가 미분 가능할 경우 } f(x) = F'(x) \right)
$$

* 주요 성질:
  1. 비음성: 모든 x에 대해 $f(x) \ge 0$
  2. 전체 확률의 합: $\int_{-\infty}^{\infty} f(x) dx = 1$
  3. 구간 확률: $P(a \le X \le b) = \int_{a}^{b} f(x) dx$
  4. 단일 점의 확률: 연속형 확률변수에서 $P(X = a) = \int_{a}^{a} f(x) dx = 0$
* **계산 예제 (미지 상수의 구명):** $f(x) = c(1-x) (0 \le x \le 1)$가 유효한 PDF가 되기 위한 상수 c 산출: $\int_{0}^{1} c(1-x) dx = c \left[ -\frac{1}{2}(1-x)^2 \right]_{0}^{1} = c \left( 0 - \left( -\frac{1}{2} \right) \right) = \frac{c}{2} = 1 \implies c = 2$

### 3.2 분위수 함수 (Quantile Function)

분위수 함수는 누적 확률 분포 함수 $F(x)$의 역함수 $F^{-1}(q)$입니다.

* CDF가 함숫값을 유지하는 평탄 구간(비감소 함수)을 가질 경우 단사 함수 조건을 만족하지 않아 일반적인 역함수가 존재하지 않을 수 있습니다.
* 이에 따라 하한(Infimum)을 이용하여 수학적으로 엄밀하게 정의합니다. $F^{-1}(q) = \inf \{ x \mid F(x) \ge q \}$

### 3.3 연속형 확률 변수의 기댓값(평균)과 분산

* **기댓값 (Mean, $\mu$):** 값과 확률(밀도)의 곱을 전 구간에 대해 적분 $E[X] = \mu = \int_{-\infty}^{\infty} x f(x) dx$
* **분산 (Variance, $\sigma^2$):** 편차 제곱의 평균 (실제 계산 시 '제곱의 평균 - 평균의 제곱' 공식 활용) $Var(X) = E[(X - \mu)^2] = \int_{-\infty}^{\infty} (x - \mu)^2 f(x) dx = E[X^2] - (E[X])^2$

### 3.4 주요 확률 분포 계산 실전 예제

#### 1) 균등 분포 (Uniform Distribution: U(a, b))

구간 [a, b] 내의 모든 지점에서 동일한 확률 밀도를 가지는 분포입니다.

* **확률 밀도 함수:** $f(x) = \frac{1}{b-a} \quad (a \le x \le b)$
* **평균 산출:** $E[X] = \int_{a}^{b} x \cdot \frac{1}{b-a} dx = \frac{1}{b-a} \left[ \frac{1}{2} x^2 \right]_{a}^{b} = \frac{b^2 - a^2}{2(b-a)} = \frac{a+b}{2}$
* **분산 산출:** $Var(X) = E[X^2] - (E[X])^2 = \int_{a}^{b} x^2 \cdot \frac{1}{b-a} dx - \left( \frac{a+b}{2} \right)^2 = \frac{(b-a)^2}{12}$

#### 2) 지수 분포 (Exponential Distribution: Exp($\lambda$))

사건이 발생할 때까지의 대기 시간을 모형화하는 분포입니다.

* **확률 밀도 함수:** $f(x) = \lambda e^{-\lambda x} \quad (x > 0)$
* **평균 산출 (부분 적분 1회 적용):** $E[X] = \int_{0}^{\infty} x \cdot \lambda e^{-\lambda x} dx = \left[ -x e^{-\lambda x} \right]_{0}^{\infty} + \int_{0}^{\infty} e^{-\lambda x} dx = 0 + \left[ -\frac{1}{\lambda} e^{-\lambda x} \right]_{0}^{\infty} = \frac{1}{\lambda}$
* **분산 산출 (부분 적분 2회 적용):** $E[X^2] = \int_{0}^{\infty} x^2 \cdot \lambda e^{-\lambda x} dx = \frac{2}{\lambda^2}$; $Var(X) = E[X^2] - (E[X])^2 = \frac{2}{\lambda^2} - \left( \frac{1}{\lambda} \right)^2 = \frac{1}{\lambda^2}$
