# 데이터 과학을 위한 수학 개론: 함수, 목적 함수 및 최적화

본 브리핑 문서는 데이터 과학의 핵심 기반이 되는 수학적 개념, 특히 함수의 역할과 종류, 그리고 모델 학습의 근간이 되는 목적 함수와 최대 우도 추정법(MLE)에 대한 심층적인 분석을 제공합니다.

## 1. 핵심 요약 (Executive Summary)

데이터 과학에서 수학은 단순한 계산 도구를 넘어 데이터 내부의 패턴을 이해하고 예측하는 핵심 언어입니다. 본 문서의 주요 내용은 다음과 같습니다.

* **함수의 역할:** 모델링을 통해 변수 간 관계를 정의하고, 새로운 입력에 대한 결과를 산출하는 예측 도구로 활용됩니다.
* **데이터 변환과 정규화:** 로그 함수와 같은 특정 함수를 사용하여 비대칭 데이터를 정규 분포에 가깝게 변환함으로써 분석의 용이성을 확보합니다.
* **최적화와 목적 함수:** 모델 학습은 목적 함수(손실 함수 최소화 또는 우도 함수 최대화)를 최적화하는 과정이며, 이는 미분 및 수치 최적화 기법을 통해 이루어집니다.
* **추정의 핵심, 최대 우도 추정법(MLE):** 관측된 데이터를 바탕으로 해당 데이터를 가장 잘 설명하는 모델의 파라미터를 찾는 수학적 방법론입니다.

## 2. 데이터 과학에서의 함수와 그 유형

함수는 입력(x)을 출력(y)으로 연결하는 규칙이며, 데이터 과학의 모든 단계에서 중추적인 역할을 수행합니다.

### 2.1 함수의 정의와 중요성

수학적으로 함수 $f: X \to Y$는 정의역 X의 임의 원소에 대해 공역 Y의 원소가 유일하게 대응되는 규칙을 의미합니다. 데이터 과학에서는 이를 통해 모델링, 최적화, 예측, 결과 해석을 수행합니다.

### 2.2 주요 함수의 종류 및 활용 사례

| 함수 유형 | 특징 | 데이터 과학 활용 사례 |
| --- | --- | --- |
| 선형 함수 | $f(x) = \beta_0 + \beta_1 x$ 형태의 1차 함수 | 단순 선형 회귀 분석에서 독립 변수와 종속 변수의 관계 설명 |
| 지수 함수 | $2^x$와 같이 급격히 증가하는 형태 (기하급수적) | 복리 계산, 감염병 확산 모델링 |
| 로그 함수 | 지수 함수의 역함수이며 양수 변수를 취급 | 소득 데이터와 같은 비대칭 분포를 정규 분포 형태로 변환 (로그 변환) |
| 다항 함수 | 변수의 거듭제곱들의 1차 결합 | 차수에 따라 다양한 곡선 형태의 모델 설계 가능 |
| 다변수 함수 | 입력 변수가 여러 개($x_1, \dots, x_n$)인 함수 | 보험료 예측 모형(나이, 성별, 직업 등 고려), 다중 선형 회귀 |
| 역함수 | 출력을 다시 입력으로 되돌리는 규칙 | 누적 분포 함수의 역함수인 '분위수 함수'를 통해 상위 고객 선별 |

## 3. 목적 함수와 최적화 원리

모델이 데이터를 얼마나 잘 설명하는지 측정하는 기준을 **목적 함수(Objective Function)**라고 합니다. 모델 학습은 이 함수를 최적화(최소화 또는 최대화)하는 파라미터를 찾는 과정입니다.

### 3.1 목적 함수의 구분

* **최소화 대상:** 손실 함수(Loss Function), 오차, 비용 기반 함수 (예: 오차 제곱합(SSE), 평균 절대 오차(MAE))
* **최대화 대상:** 확률 및 우도(Likelihood) 기반 함수

### 3.2 최적화 기법

수학적 접근을 통해 최적의 값을 도출합니다.

* **미분:** 극값이나 최소/최댓값을 탐색
* **수치 최적화:** 경사 하강법(Gradient Descent), 뉴턴 방법(Newton's Method)

## 4. 우도(Likelihood)와 확률의 이해

데이터 과학에서 모델의 파라미터를 추정할 때 '우도'와 '확률'의 개념적 차이를 명확히 이해하는 것이 필수적입니다.

### 4.1 개념적 대비

| 구분 | 확률 (Probability) | 우도 (Likelihood) |
| --- | --- | --- |
| 고정 요소 | 파라미터($\theta$)가 고정됨 | 관측된 데이터($x$)가 고정됨 |
| 변동 요소 | 사건 데이터($x$)의 발생 가능성 계산 | 파라미터($\theta$)의 적합도 계산 |
| 주요 용도 | 예측(Prediction) 및 생성 | 추정(Estimation) 및 학습 |
| 핵심 질문 | "이 모델에서 데이터가 나올 확률은?" | "이 데이터를 가장 잘 설명하는 모델은?" |

### 4.2 로그 우도 함수(Log-Likelihood)의 활용

복수의 관측값에 대한 우도 함수는 개별 우도의 곱으로 정의됩니다. 그러나 곱셈 형태는 미분과 최적화 계산이 복잡하므로, 우도 함수에 로그를 취하여 덧셈 형태로 변환한 로그 우도 함수를 주로 사용합니다. 로그 함수는 단조 증가 함수이므로 로그 우도를 최대화하는 파라미터는 원래의 우도를 최대화하는 파라미터와 동일합니다.

## 5. 최대 우도 추정법(MLE) 실증 분석

정규 분포를 따르는 데이터를 대상으로 최대 우도 추정법을 적용한 결과, 이론적 공식과 수치 최적화 결과가 일치함이 확인되었습니다.

### 5.1 정규 분포에서의 MLE 도출 결과

평균($\mu$)과 분산($\sigma^2$)을 모르는 정규 분포 데이터 n개가 주어졌을 때:

* **평균의 MLE:** 표본 평균과 동일함.
* **분산의 MLE:** 편차 제곱의 평균 (주의: 일반적인 표본 분산 공식의 n-1이 아닌 n으로 나눔).

### 5.2 파이썬 실습을 통한 검증

1. 데이터 생성: 평균 5, 분산 4인 정규 분포에서 100개의 난수 생성.
2. 최적화 수행: SciPy의 minimize 함수를 사용하여 음의 로그 우도 함수를 최소화.
3. 결과 확인: 최적화를 통해 찾은 파라미터값($\mu \approx 4.79, \sigma^2 \approx 3.26$)이 이론적 공식으로 계산한 값과 소수점 끝자리까지 일치함을 확인.
4. 시각적 검증: 추정된 파라미터를 바탕으로 그린 확률 밀도 함수(PDF)가 실제 데이터의 히스토그램 분포를 매우 정교하게 설명함.

## 6. 결론

데이터 과학에서 함수는 데이터를 해석하고 예측 모델을 수립하는 근본적인 도구입니다. 특히 **최대 우도 추정법(MLE)**은 관측된 데이터를 기반으로 최적의 모델 파라미터를 결정하는 강력한 수학적 기법입니다. 목적 함수를 설정하고 이를 최적화하는 일련의 과정은 데이터 과학의 학문적 핵심이며, 이를 통해 데이터로부터 유의미한 의사 결정을 지원할 수 있습니다.
