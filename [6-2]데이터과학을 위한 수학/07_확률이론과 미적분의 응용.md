# 제7강 확률이론과 미적분의 응용

## 1. 핵심 요약 (Executive Summary)

본 브리핑 문서에서는 확률이론 및 데이터 과학 분야에서 미분과 적분이 가지는 이론적 역할과 실제적 응용 사례를 종합적으로 분석한다. 주요 핵심 내용은 다음과 같다.

* 연속확률분포와 적분: 연속형 확률변수의 확률밀도함수(PDF) 및 결합·주변·조건부 확률분포의 정의와 확률 계산, 기대값 산출은 이중적분 및 반복적분(푸비니 정리)을 기초로 수행된다.
* 조건부 기대값의 성질: 조건부 기대값에 다시 기대값을 취하면 원래 확률변수의 전체 평균과 같아진다($E[E[X|Y]] = E[X]$).
* 베이즈 정리와 사후 분포: 베이즈 정리는 사전 지식(Prior)에 관측 데이터의 우도(Likelihood)를 결합하여 사후 분포(Posterior)를 업데이트하는 정량적 프레임워크를 제공한다.
* 정규분포 CDF의 수치 계산: 표준정규분포의 누적분포함수(CDF)는 닫힌 형태(Closed-form)의 해석적 적분이 불가능하므로, 오차 함수(Error Function) 및 테일러 급수를 통한 수치적 미적분 근사 기법을 사용한다.
* 데이터 과학 및 머신러닝 응용: 머신러닝 최적화 과정에서 볼록 손실함수(예: 오차제곱합)의 최소화, 베이지안 사후 분포의 정규화 상수 적분, 분위수 및 모수 추정 등 전 분야에서 미적분이 핵심 도구로 작용한다.

## 2. 결합·주변·조건부 확률 분포와 미적분

### 연속형 확률변수와 확률밀도함수(PDF)

연속형 확률변수 X의 확률밀도함수 $f(x)$는 다음과 같은 조건과 성질을 가진다.

1. 함숫값은 항상 0 이상이다: $f(x) \ge 0$
2. 전체 범위에 대한 적분값은 1이다: $\int_{-\infty}^{\infty} f(x) dx = 1$
3. 특정 구간 [a, b]에 포함될 확률은 정적분으로 계산된다: $P(a \le X \le b) = \int_{a}^{b} f(x) dx$
4. 누적확률분포함수(CDF) $F(x)$는 $-\infty$부터 x까지의 적분으로 정의된다: $F(x) = \int_{-\infty}^{x} f(t) dt$

### 결합확률밀도함수 (Joint PDF)

둘 이상의 확률변수를 나타내는 다변수 함수 $f(x, y)$ 역시 $f(x, y) \ge 0$을 만족하며 실수 전체 영역에 대한 이중적분 값이 1이 되어야 한다.

* 확률 계산: 영역 A에 포함될 확률 $P((X, Y) \in A) = \iint_A f(x, y) dx dy$ (곡면 아래의 부피)
* 예제: 결합확률밀도함수 $f(x, y) = 4xy$ ($0 \le x \le 1, 0 \le y \le 1$)
  * 전체 범위 적분: $\int_0^1 \int_0^1 4xy dx dy = 1$로 정당한 Joint PDF임.
  * $P(0 \le X \le 0.5, 0 \le Y \le 0.5)$ 계산: 반복적분을 수행하면 $\int_0^{0.5} \int_0^{0.5} 4xy dx dy = \frac{1}{16}$이 도출된다.

### 주변확률밀도함수 (Marginal PDF)

결합확률밀도함수에서 특정 확률변수를 제외한 나머지 변수를 적분하여 제거함으로써 한 확률변수만의 분포를 나타내는 함수이다.

* X의 주변확률밀도함수: $f_X(x) = \int_{-\infty}^{\infty} f(x, y) dy$
* Y의 주변확률밀도함수: $f_Y(y) = \int_{-\infty}^{\infty} f(x, y) dx$

### 예제 및 독립성(Independence) 판단

삼각형 정의역 $0 \le y < x \le 1$에 정의된 $f(x, y) = 8xy$의 경우:

* $f_X(x) = \int_0^x 8xy dy = 4x^3$
* $f_Y(y) = \int_y^1 8xy dx = 4y(1 - y^2)$
* 독립성 판정: $f(x, y) = f_X(x) f_Y(y)$가 성립해야 두 변수가 독립이다. 위 예제는 $4x^3 \times 4y(1 - y^2) \neq 8xy$이므로 독립이 아니다(정의역의 범위가 서로에게 의존적임). 반면, 사각형 영역 $[0, 1] \times [0, 1]$에서 정의된 $f(x, y) = 4xy$는 $f_X(x)=2x, f_Y(y)=2y$가 되어 두 곱이 결합분포와 같으므로 서로 독립이다.

### 조건부 확률밀도함수 (Conditional PDF)

사건 $Y=y$가 발생했다는 조건 하에 X의 확률밀도함수를 의미한다. 전체 영역이 y가 일어날 확률(주변 분포)로 축소된다.

* 정의: $f_{X|Y}(x|y) = \frac{f(x, y)}{f_Y(y)}$ (단, $f_Y(y) > 0$)
* y가 고정된 상수값으로 부여되면 $f_{X|Y}(x|y)$는 X에 대한 단변량 확률변수 및 함수가 된다.

| 구분                     | 주변 확률밀도함수 ($f_X(x)$)    | 조건부 확률밀도함수 ($f_{X\mid Y}(x\mid y)$)                               |
| :----------------------- | :-------------------------------- | :--------------------------------------------------------------------------- |
| 의미                     | Y 전체에 대해 평균적인 X의 분포   | 특정 $Y=y$ 조건 하에서의 X의 분포                                          |
| 변수 구성                | Y가 적분되어 제거됨 (y 미포함)    | 고정된 조건 y값에 의존함 (y 포함)                                            |
| 예시 형태 (8xy 삼각영역) | $f_X(x) = 4x^3$ (0~1 사이 곡선) | $f_{X\mid Y}(x\mid y)$ = $\frac{2x}{1-y^2}$ ($y \le x \le 1$ 1차 직선) |

## 3. 조건부 기대값과 기대값의 성질

### 푸비니 정리와 결합 분포의 기대값

이변수 확률밀도함수 $f(x, y)$에 대한 X의 기대값 $E[X]$는 이중적분으로 정의되며, 푸비니 정리(Fubini's Theorem)에 의해 반복적분으로 전환할 수 있다. $E[X] = \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} x f(x, y) dy dx = \int_{-\infty}^{\infty} x \left( \int_{-\infty}^{\infty} f(x, y) dy \right) dx = \int_{-\infty}^{\infty} x f_X(x) dx$

### 조건부 기대값 및 조건부 기대값의 기대값 정리

* 조건부 기대값: $Y=y$가 주어졌을 때 X의 기대값은 $E[X|Y=y] = \int_{-\infty}^{\infty} x f_{X|Y}(x|y) dx$ 로 정의되며, 이는 y에 관한 함수 $g(y)$이다.
* 조건부 기대값의 기대값 (Law of Total Expectation): 조건부 기대값 $E[X|Y]$에 대해 다시 Y 관점의 기대값을 취하면 본래의 $E[X]$와 동일하다.

$$
\begin{aligned}
E[E[X|Y]] &= \int_{-\infty}^{\infty} \left[ \int_{-\infty}^{\infty} x f_{X|Y}(x|y) dx \right] f_Y(y) dy \\
&= \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} x \cdot f_{X|Y}(x|y) f_Y(y) dx dy \\
&= \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} x f(x, y) dx dy = E[X]
\end{aligned}
$$

## 4. 베이즈 정리와 사후 분포 (Bayesian Inference)

### 베이즈 정리의 구조

조건부 확률의 정의를 확률밀도함수에 적용하여 관측 데이터를 바탕으로 모수(파라미터)에 대한 지식을 업데이트하는 공식이다.

$$
f(\theta|y) = \frac{f(y|\theta) f(\theta)}{f(y)}
$$

* 사후 분포 (Posterior, $f(\theta|y)$): 데이터 y가 관측된 후 파라미터 $\theta$에 대한 확률밀도함수.
* 우도 함수 (Likelihood, $f(y|\theta)$): 특정 파라미터 $\theta$가 주어졌을 때 데이터 y가 관측될 가능성.
* 사전 분포 (Prior, $f(\theta)$): 데이터 관측 전 파라미터 $\theta$에 대해 보유한 사전 지식.
* 정규화 상수 (Normalization Constant, $f(y)$): $\theta$와 무관한 상수로, 사후 분포의 전체 적분값을 1로 맞추어 주는 역할하며 $f(y) = \int f(y|\theta) f(\theta) d\theta$ 로 계산된다.
* 개념적 핵심: $\text{Posterior} \propto \text{Likelihood} \times \text{Prior}$ (사후 분포는 우도와 사전 분포의 곱에 비례함)

### 사후 분포 계산 예제

#### 1. 정규분포 데이터와 균등 사전분포

* 조건: 관측 데이터 $y \sim N(\theta, \sigma^2)$, 평균 모수 $\theta$의 사전 분포는 균등분포 $U(0, 1)$ ($0 \le \theta \le 1$에서 함숫값 1).
* 계산: 사후 분포 $f(\theta|y) \propto \exp\left(-\frac{(y-\theta)^2}{2\sigma^2}\right) \times 1 \quad (0 \le \theta \le 1)$
* 결과: 관측값 $y=0.5, \sigma^2=1$일 때, 사후 분포는 0과 1 사이의 영역으로 제한되어 더 뾰족한 형태를 띠는 절단된 정규분포(Truncated Normal Distribution) $TN(0.5, 1)$ 형태를 갖는다.

#### 2. 이항분포 데이터와 베타 사전분포

* 조건: 시행횟수 n, 성공횟수 y인 이항분포 우도 $f(y|\theta) \propto \theta^y (1-\theta)^{n-y}$ 및 베타 사전분포 $\theta \sim Beta(\alpha, \beta) \propto \theta^{\alpha-1} (1-\theta)^{\beta-1}$.
* 계산: $f(\theta|y) \propto \left[ \theta^y (1-\theta)^{n-y} \right] \times \left[ \theta^{\alpha-1} (1-\theta)^{\beta-1} \right] = \theta^{(\alpha+y)-1} (1-\theta)^{(\beta+n-y)-1}$
* 결과: 사후 분포는 모수가 업데이트된 베타 분포 $Beta(\alpha+y, \beta+n-y)$를 따른다.
* 수치 사례: 사전 분포 $Beta(2, 2)$인 상태에서 $n=10$번 중 $y=5$번 성공을 관측하면, 사후 분포는 $Beta(7, 7)$로 업데이트된다.

## 5. 정규분포 누적분포함수의 수치적 계산

### 표준화 및 적분 불가능성

정규분포 $X \sim N(\mu, \sigma^2)$의 누적분포함수 계산은 표준 정규변수 $Z = \frac{X-\mu}{\sigma} \sim N(0, 1)$의 누적분포함수 $\Phi(z)$로 전환된다. $\Phi(z) = \int_{-\infty}^{z} \frac{1}{\sqrt{2\pi}} e^{-\frac{t^2}{2}} dt = 0.5 + \int_{0}^{z} \frac{1}{\sqrt{2\pi}} e^{-\frac{t^2}{2}} dt$ 피적분함수 $e^{-\frac{t^2}{2}}$는 지수 형태의 적분 불가능 함수로, 초등함수 형태의 해석적(Analytical) 적분 결과를 얻을 수 없다.

### 오차 함수(Error Function) 및 테일러 급수 활용

해석적 적분이 불가능하므로 수치해석적 기법을 사용한다.

1. 오차 함수 정의: $ERF(z) = \frac{2}{\sqrt{\pi}} \int_0^z e^{-t^2} dt$ ($z \to \infty$ 일 때 1로 수렴하도록 상수 조정)
2. 변수 치환: 오차 함수 ERF의 치환을 통해 표준정규분포의 CDF $\Phi(z)$를 표현함.
3. 수치 계산: 테일러 급수(Taylor Series) 등 미분을 활용한 근사식을 적용하여 계산을 수행한다. Python 등의 프로그래밍 언어 및 표준 정규분포표는 약 $10^{-7}$ 수준의 오차 범위를 갖는 근사식을 통해 수치 적분값을 산출한다.

## 6. 머신러닝 및 데이터 과학에서의 미적분 응용

데이터 과학 전반에서 미적분은 이론적 뼈대 및 계산 도구로 다음과 같이 다양하게 적용된다.

```text
[데이터 과학 내 미적분 응용 구조]
├── 최적화 (Optimization)      : 손실함수(Loss Function) 극소화 및 파라미터 추정
├── 수치 계산 (Approximation)   : 테일러 급수를 이용한 함수 근사 및 ERF 계산
├── 확률 및 통계량 산출         : 누적확률, 분위수, 기대값, 분산, 공분산 계산
└── 베이지안 추론 (Inference)   : 사후 분포의 정규화 상수 분모 적분 (Normalization)
```

1. 손실함수 최적화: 머신러닝 모델 학습은 정의된 손실함수(Loss Function)를 최소화하는 과정이다. 손실함수를 오차제곱합(SSE)과 같은 볼록 함수(Convex Function)로 정의하면 극소값이 곧 최소값이 되므로 초기값과 무관하게 최적 파라미터를 안정적으로 탐색할 수 있다.
2. 사후 분포 정규화 상수 적분: 베이지안 추론에서 정확한 사후 확률밀도함수를 구하려면 분모의 주변 확률밀도함수 $f(y) = \int f(y|\theta)f(\theta) d\theta$ 적분을 수행해야 한다. 이는 통계적 모델 선택, 신뢰구간 설정, 예측 분포 산출의 필수 단계이다.
3. 통계량 산출: 연속확률변수의 기대값, 분산, 공분산 계산 및 조건부 확률 산출 등 모수적 추론 전반에 적분 개념이 광범위하게 적용된다.
