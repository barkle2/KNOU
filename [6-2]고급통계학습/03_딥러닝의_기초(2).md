# 딥러닝의 기초: 다층 신경망 구조와 오차 역전파 알고리즘의 심층 분석

## 핵심 요약 (Executive Summary)

본 보고서는 초기 신경망 모델인 퍼셉트론의 한계를 극복하고 현대 딥러닝의 초석이 된 **다층 신경망(Multi-Layer Perceptron, MLP)**의 구조와 학습 원리를 상세히 분석한다. 핵심 내용은 비선형 문제 해결을 위한 **은닉층(Hidden Layer)**의 도입, 임의의 함수를 근사할 수 있는 일반 근사 정리(Universal Approximation Theorem), 그리고 복잡한 가중치 업데이트를 가능하게 한 오차 역전파(Backpropagation) 알고리즘으로 요약된다. 특히, 신경망의 깊이(Depth)가 정확도 향상에 미치는 영향과 '기울기 소실(Vanishing Gradient)'과 같은 기술적 난제를 활성화 함수(ReLU 등) 및 컴퓨팅 파워의 발전으로 해결해 온 과정을 중점적으로 다룬다.

## 1. 신경망의 구조적 진화: 퍼셉트론에서 딥러닝으로

### 1.1 초기 모델의 한계와 은닉층의 도입

초기 신경망 모델인 퍼셉트론(Perceptron)과 아델라인(Adaline)은 입력층과 출력층만으로 구성되어 선형적인 문제만을 해결할 수 있었다. 이러한 비선형 문제 해결의 불가능성을 극복하기 위해 입력층과 출력층 사이에 **은닉층(Hidden Layer)**을 추가한 다층 신경망 구조가 고안되었다.

* 순방향 신경망(Feedforward Neural Network): 데이터가 입력층에서 은닉층을 거쳐 출력층으로만 전달되는 구조이다.
* 합성 함수로서의 신경망: 각 층을 통과할 때마다 함수가 적용되므로, 신경망 전체는 거대한 누적 합성 함수로 볼 수 있다.
* 깊이(Depth)와 넓이(Width): 뉴런의 개수는 '넓이', 은닉층의 개수는 '깊이'를 의미하며, 은닉층이 많은 모형을 심층 신경망(Deep Neural Network, DNN) 또는 딥러닝이라 부른다.

### 1.2 보편적 함수 근사기로서의 신경망

현대 신경망은 단순히 뇌를 모사하는 단계를 넘어, 임의의 함수를 근사하는 '유니버설 머신(Universal Machine)'으로 이해된다.

* 일반 근사 정리(Universal Approximation Theorem): 하나 이상의 충분한 크기를 가진 은닉층을 포함한 순방향 신경망은 모든 유계 연속 함수(Bounded Continuous Function)를 근사할 수 있다. (1989년 사이코가 시그모이드 함수에 대해 증명 후 호익이 일반화함)

## 2. 활성화 함수(Activation Function)의 유형과 역할

활성화 함수는 신경망에 비선형성을 부여하는 핵심 요소이다. 선형 함수만을 사용하면 층을 아무리 깊게 쌓아도 결국 하나의 선형 회귀 모형과 동일해지기 때문에, 비선형 활성화 함수의 사용은 필수적이다.

| 함수명 | 특징 | 출력 범위 | 비고 |
| --- | --- | --- | --- |
| 계단 함수 (Step) | 임계치를 넘으면 활성화 | 0 또는 1 | 초기 퍼셉트론에서 사용 |
| 시그모이드 (Sigmoid) | 매끄러운 곡선, 로지스틱 회귀와 연결 | 0 ~ 1 | 미분 가능하나 깊은 층에서 문제 발생 |
| 하이퍼볼릭 탄젠트 (Tanh) | 시그모이드와 유사하나 중심이 0 | -1 ~ 1 | 시그모이드보다 선호되기도 함 |
| ReLU (Rectified Linear Unit) | 0보다 작으면 0, 크면 선형 값 유지 | 0 ~ 무한대 | 현대 딥러닝에서 가장 널리 사용 |

## 3. 다층 신경망의 수학적 연산 구조

신경망의 연산은 대량의 데이터를 빠르게 처리하기 위해 행렬(Matrix) 표현을 사용한다.

1. 선형 결합 (Z): 입력 값(X)에 가중치(W)를 곱하고 편향(B)을 더한다. (G = XW + B)
2. 활성화 (A): 선형 결합 결과값에 활성화 함수(g)를 적용한다. (A = g(G))
3. 출력 결정:
   * 회귀: 선형 활성화 함수를 사용하여 수치 예측.
   * 이진 분류: 시그모이드 함수 사용.
   * 다중 분류: 소프트맥스(Softmax) 함수와 크로스 엔트로피 손실 함수 사용.

## 4. 학습 알고리즘: 오차 역전파(Backpropagation)

### 4.1 개념 및 역사적 배경

오차 역전파는 손실 함수의 기울기(Gradient)를 효율적으로 계산하여 가중치를 업데이트하는 알고리즘이다. 1960~70년대에 이미 제안되었으나 낮은 컴퓨팅 파워로 인해 주목받지 못하다가, 1986년 힌튼(Hinton) 등에 의해 재발견되며 인공지능의 부흥기를 이끌었다.

### 4.2 연쇄 법칙(Chain Rule)과 계산 그래프

오차 역전파는 미분의 연쇄 법칙을 기반으로 한다. 복잡한 합성 함수의 미분을 직접 구하는 대신, 계산 그래프를 그려 순방향으로 계산된 값을 저장하고 역방향으로 미분값을 전달하며 최종 기울기를 구한다.

* 순전파(Forward Pass): 입력 데이터를 통해 예측값과 손실 함수를 계산.
* 역전파(Backward Pass): 출력층에서 발생한 오차를 입력층 방향으로 역전파하며 각 가중치에 대한 기울기를 계산.

## 5. 신경망 깊이의 효과와 주요 난제

### 5.1 깊은 층의 필요성

연구에 따르면 동일한 파라미터(모수) 수일 때, 뉴런의 개수(넓이)를 늘리는 것보다 층의 개수(깊이)를 늘리는 것이 정확도 향상에 훨씬 효과적이다. 층이 깊어질수록 데이터로부터 더 추상적인 특징을 추출할 수 있기 때문이다.

### 5.2 기술적 한계와 해결책

* 기울기 소실(Vanishing Gradient): 시그모이드나 탄젠트 함수를 사용하여 층을 깊게 쌓을 경우, 역전파 과정에서 미분값이 반복적으로 곱해지며 0에 수렴하게 되어 앞쪽 층의 가중치가 업데이트되지 않는 현상이다.
* 과적합(Overfitting): 훈련 데이터에 너무 과하게 최적화되어 새로운 데이터에 대한 성능이 떨어지는 문제이다.
* 해결 방법:
   * ReLU 활성화 함수 도입으로 기울기 소실 완화.
   * 드롭아웃(Dropout) 등 알고리즘적 개선.
   * 빅데이터의 확보와 강력한 컴퓨팅 파워(GPU 등) 활용.

## 6. 결론

딥러닝 학습의 본질은 훈련 데이터의 손실 함수를 최소화하는 최적의 가중치 조합을 찾는 과정이다. 이는 경사하강법과 오차 역전파를 통해 반복적으로 수행되며, 신경망을 '유니버설 함수 근사기'로 기능하게 한다. 비록 기울기 소실과 과적합이라는 난관이 존재했으나, 알고리즘적 혁신과 기술적 자원의 풍요가 이를 극복하게 함으로써 현대 인공지능의 성취를 가능케 하였다.
