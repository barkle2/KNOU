# 제7강 합성곱 신경망 (2)

## 핵심 요약 (Executive Summary)

본 보고서는 합성곱 신경망(Convolutional Neural Network, CNN)의 역사적 발전 과정, 주요 아키텍처별 구조적 혁신, 그리고 실무 적용 핵심 기술인 전이 학습(Transfer Learning)에 대한 주요 내용을 종합 분석한 문서이다.

* CNN 아키텍처의 진화: 1998년 LeNet-5를 시작으로 2012년 AlexNet의 등장에 힘입어 딥러닝이 본격화되었다. 이후 필터 크기 축소와 채널 확장(VGGNet), 병렬 필터 연산 및 1x1 컨볼루션을 통한 차원 축소(GoogLeNet), 그리고 지름길 연결(Skip Connection)을 통한 경사 소실 문제 해결(ResNet)로 이어지며 모델은 점차 '더 깊고(Deeper), 더 효율적(Efficient)'으로 발전했다.
* 연산 효율 극대화 기법: 1x1 합성곱 필터의 도입은 연산량을 약 1/10 수준으로 획기적으로 줄였으며, 3x3 필터를 여러 층 중첩하는 방식은 파라미터 수 절감 및 비선형성 증대 효과를 가져왔다.
* 초극심층 네트워크의 구현: ResNet은 잔차 블록(Residual Block) 기반의 스킵 연결을 도입하여 152개의 계층을 쌓아 올림으로써 인간의 인식 오차율(약 5%)보다 뛰어난 3.6%의 오차율을 달성했다.
* 전이 학습의 핵심 가치: 대규모 사전 학습 모델(Pre-trained Model)의 가중치를 재활용하는 전이 학습은 모델 구축 시 요구되는 방대한 데이터 및 컴퓨팅 자원의 한계를 극복하게 하며, 학습 시작점 개선, 빠른 수렴, 높은 최종 성능 향상을 가능하게 한다.

## 1. CNN의 고전적 기원 및 초기 모델

### 1.1 시각 피질 연구와 초기 신경망

* 생물학적 기반: 허블(Hubel)과 위셀(Wiesel)의 시각 피질 연구를 바탕으로 국부적 연결 및 계층적 추상화 개념이 도입되었다.
* 네오코그니트론 (Neo-Cognitron): 후쿠시마(Fukushima)가 제안한 모형으로, 국부적 특성을 추출하는 **S셀(S-cell)**과 이를 합성/집계하는 **C셀(C-cell)**로 구성되어 현대 CNN의 계층적 구조 및 국부 수용야 개념의 효시가 되었다.

### 1.2 LeNet-5 (1998년, 얀 르쿤)

* 개요: 수표의 손글씨 숫자를 인식하기 위해 개발된 최초의 실용적 CNN 구조이다.
* 입력 및 구조:
  * 32x32 해상도의 정규화된 이미지 입력.
  * 5x5 합성곱 필터와 2x2 평균 풀링(Average Pooling)의 반복 적용.
  * 활성화 함수로 하이퍼볼릭 탄젠트(tanh) 사용.
* 최종 출력: 소프트맥스(Softmax) 대신 입력/출력 벡터 간 유클리디안 거리를 활용하는 **RBF(Radial Basis Function)**를 분류기로 사용.
* 파라미터 규모: 약 3만~34만 개의 학습 가능한 가중치(Weight) 존재.

## 2. 딥러닝 부흥과 대규모 CNN 발전 (2012~2014)

### 2.1 AlexNet (2012년, 알렉스 크리체프스키 & 제프리 힌튼)

ImageNet 경진대회(ILSVRC)에서 5개 범주 내 오차율을 기존 28%대에서 **16.4%**로 급격히 낮추며 딥러닝 열풍을 주도한 모델이다.

* 구조적 특징:
  * 총 8개 계층(컨볼루션 5개, 전결합 3개)으로 구성.
  * 당시 GPU 성능 한계(듀얼 GPU)로 인해 2개의 병렬 스트림 구조로 논문 작성 (227x227x3 입력).
* 주요 기술적 혁신:
  * ReLU 활성화 함수 최초 적극 도입: 하이퍼볼릭 탄젠트 대비 학습 속도 향상.
  * 드롭아웃(Dropout 0.5): 전결합층(Fully Connected Layer) 과적합 방지.
  * 데이터 증강(Data Augmentation): 데이터 부족 문제 완화.
  * 앙상블 기법: 7개 모델의 앙상블을 통해 2~3% 추가 오차율 감소.
  * 학습 설정: 모멘텀(0.9) 기반 SGD, 배치 사이즈 128.

### 2.2 ZFNet (2013년, 자일러 & 퍼거스)

* AlexNet의 기본 구조를 유지하면서 초반 계층의 필터 크기와 스트라이드(Stride)를 수정하여 성능을 개선한 모델.
* 첫번째 Conv 층: 11x11 (stride 4) → 7x7 (stride 2)로 축소.
* Conv 3, 4, 5의 필터 채널 수를 확대(512, 1024, 512)하여 정확도 향상.

### 2.3 VGGNet (2014년, 옥스포드 대학 VGG 팀)

ILSVRC 2014에서 2위를 차지했으나, 구조의 간결성과 일관성 덕분에 실무에서 가장 광범위하게 활용된 네트워크이다.

* 구조적 특징:
  * 모든 컨볼루션 레이어에 3x3 소형 필터와 **2x2 맥스 풀링(Max Pooling)**만 반복 적용.
  * 가장 뛰어난 성과를 보인 VGG16(16개 층) 및 VGG19 모델이 대표적.
  * 채널 수는 풀링을 거칠 때마다 64 → 128 → 256 → 512 방식으로 2의 거듭제곱 형태로 증가.
* 한계점:
  * 후반부 전결합층(FC Layer)으로 인해 파라미터 수가 **약 1억 3천만 개(130M)**에 달해 메모리 요구량과 연산량이 과다함.

## 3. 연산 효율성 극대화 및 초극심층 구조 혁신 (2014~2015)

### 3.1 GoogLeNet / Inception Network (2014년, 구글)

ILSVRC 2014 우승 모델로, 깊이는 22개 층으로 늘리면서도 파라미터 수는 AlexNet의 1/12 수준인 약 400만~500만 개로 대폭 축소하였다 (오차율 6.7%).

```text
[Inception Module 개념]
             ┌─ 1x1 Conv ─────────────────────────┐
             ├─ 1x1 Conv ──> 3x3 Conv ────────────┤
Previous ───►├─ 1x1 Conv ──> 5x5 Conv ────────────┼──► Depth Concatenate (Stacking)
Layer        └─ 3x3 Max Pooling ──> 1x1 Conv ─────┘
```

* 인셉션 모듈 (Inception Module):
  * 다양한 크기(1x1, 3x3, 5x5)의 필터와 맥스 풀링을 병렬로 동시 적용한 후 결과를 채널 축으로 결합(Stacking)하는 방식.
  * 필터 크기 선택의 고민을 해결하고 다양한 스케일의 특성을 동시 수용.
* 1x1 컨볼루션을 통한 차원 축소 (Bottleneck Layer):
  * 3x3 또는 5x5 연산 이전에 1x1 컨볼루션을 배치하여 채널 수를 줄임으로써 계산 복잡도를 기존 대비 약 1/10 수준으로 격감시킴.
* 보조 분류기 (Auxiliary Classifier):
  * 학습 과정 중 중간 레이어 결과에 2개의 보조 분류기를 붙여 로스(Loss)를 계산 ($L_{\mathrm{total}} = L_{\mathrm{main}} + 0.3L_{\mathrm{aux},1} + 0.3L_{\mathrm{aux},2}$).
  * 역전파 시 경사 소실(Vanishing Gradient) 문제를 완화하며, 추론(Inference) 단계에서는 보조 분류기를 제거함.

### 3.2 ResNet (2015/2016년, 마이크로소프트 카이밍 허)

ILSVRC 2015 우승 모델로, 레이어를 152개 층까지 극단적으로 깊게 쌓았음에도 오차율을 **3.6%**로 낮춰 인간 수준(약 5%)을 최초로 뛰어넘었다.

* 지름길 연결 (Skip Connection / Shortcut Connection):
  * 층이 깊어질수록 성능이 오히려 저하되는 degradation 문제를 해결하기 위해 입력 $A_L$을 출력단에 직접 더해주는 잔차 학습(Residual Learning) 모듈 도입.
  * 수식 표현: $A_{L+2} = g(Z_{L+2} + A_L)$ (여기서 g는 활성화 함수).
  * 입력값을 지름길로 전달하므로 역전파 시 기울기(Gradient)가 손실 없이 상위 층까지 신속하게 전달됨.
* 학습 기법 및 특징:
  * 배치 정규화(Batch Normalization) 전면 적용: 드롭아웃(Dropout) 적용 필요성 제거.
  * 학습률(Learning Rate) 0.1, 배치 사이즈 256 사용.
  * 학습 시간은 대규모 데이터 기준 2~3주 소요되나, 추론 시의 연산 효율성은 우수함.

| --------- | --------- | --------- | -------------- | ------------ | ------------------------------------------------- |

| VGG16     | 2014      | 16        | 약 1억 3,000만 | -            | 3x3 필터 단일화, 높은 연산량 및 단순 구조         |

## 5. 네트워크 깊이(Depth) 확장의 이론적 근거

작은 크기의 필터를 여러 층 쌓는 구조(예: 3x3 필터의 중첩)가 대형 필터 하나를 사용하는 것보다 유리한 이유는 다음과 같다.

1. 수용 영역(Receptive Field)의 동일성 및 파라미터 절감:
   * 3x3 필터를 2번 중첩하면 5x5 필터 1개와 동일한 영역을 거버함.
     * 5x5 1개 연산량: $5 \times 5 = 25$ 파라미터
     * 3x3 2개 연산량: $3 \times 3 \times 2 = 18$ 파라미터 (약 28% 감소)
   * 3x3 필터를 3번 중첩하면 7x7 필터 1개와 동일한 영역을 거버함.
     * 7x7 1개 연산량: $7 \times 7 = 49$ 파라미터
     * 3x3 3개 연산량: $3 \times 3 \times 3 = 27$ 파라미터 (약 45% 감소)
2. 비선형성(Non-linearity) 증대:
   * 층이 늘어날 때마다 ReLU와 같은 비선형 활성화 함수를 가미하므로, 모델의 표현력(Representational Power)이 대폭 강화된다.

## 6. 전이 학습 (Transfer Learning)

### 6.1 전이 학습의 개요 및 필요성

* 개념: 대규모 데이터셋(ImageNet 등)으로 이미 사전 학습된(Pre-trained) 가중치를 가져와 새로운 대상 문제에 재활용하는 학습 기법.
* 도입 배경: 처음부터(From Scratch) 신경망을 설계하고 학습시키는 것은 대규모 GPU 자원, 수주 이상의 시간, 대용량 라벨링 데이터가 필요하여 현실적 제약이 큼.
* 전이 학습의 3대 장점:
  1. 우수한 출발점(Higher Start): 무작위 초기화보다 훨씬 높은 초기 성능에서 출발.
  2. 빠른 수렴(Faster Convergence): 학습 속도 및 수렴 시간이 대폭 단축.
  3. 최종 성능 향상(Higher Asymptote): 데이터가 적은 상황에서도 더 높은 최종 정확도 달성.

### 6.2 데이터 상황별 전이 학습 적용 전략

```text
                   [데이터 유사도 높음]
              ┌───────────────────────────┐
              │  - 초기 층 가중치 고정    │
              │  - 분류기(FC)만 학습      │
              └─────────────┬─────────────┘
                            │
[데이터 소량] ──────────────┼────────────── [데이터 대량]
                            │
              ┌─────────────┴─────────────┐
              │  - 중간 층까지 고정 확충  │
              │  - 전체/하위 층 미세조정  │
              └───────────────────────────┘
                   [데이터 유사도 낮음]
```

1. 소량 데이터 & 유사도 높음:
   * 기존 특징 추출기(Feature Extractor) 가중치를 완전히 고정(Freeze)하고, 마지막 분류기(FC Layer)만 새로 학습.
2. 대량 데이터 & 유사도 높음:
   * 사전 학습 가중치를 초기값으로 사용하되, 전체 네트워크 또는 하위 레이어 일부를 낮은 학습률(Learning Rate)로 미세 조정(Fine-tuning).
3. 소량 데이터 & 유사도 낮음 (예: 의료 X-ray/MRI 등):
   * 초반의 아주 기초적인 엣지(Edge) 추출 층만 고정하고, 나머지 층을 넓게 재학습하거나 사전 학습 모델의 활용 범위를 신중하게 조율.
4. 대량 데이터 & 유사도 낮음:
   * 많은 레이어를 미세 조정하거나 전체를 새로 학습시키는 방향 선택.

### 6.3 실증적 효과 및 모델 주(Model Zoo)

* 실험적 결과: 처음부터 학습시킬 경우 몇 백 번의 이터레이션 후에도 정확도가 20~28% 수준에 머무는 반면, 사전 학습된 가중치를 로드(Load)하여 적용할 경우 즉각적으로 약 80% 이상의 정확도를 확보할 수 있음.
* 모델 주(Model Zoo) 활용: PyTorch, TensorFlow, Keras 등 주요 딥러닝 프레임워크는 ResNet, VGG, Inception 등 검증된 모델의 가중치를 제공하므로, 개발자는 이를 인프라 구축 없이 즉시 불러와 파이프라인에 적용 가능함.
