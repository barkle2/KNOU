# 제4강 딥러닝의 제문제와 발전(1)

## 요약 (Executive Summary)

본 보고서는 딥러닝 모델이 직면했던 핵심적인 기술적 난제들과 이를 극복하기 위한 발전 과정을 분석한다. 전통적인 통계 모형과 딥러닝 모형의 차이점을 시작으로, 다층 신경망(MLP) 학습의 중심인 오차 역전파법에서 발생하는 문제들을 상세히 다룬다.

가장 치명적인 문제였던 **그레디언트 소실(Gradient Vanishing)**은 활성화 함수를 시그모이드(Sigmoid)에서 렐루(ReLU) 계열로 전환함으로써 해결되었으며, 가중치 초기값 설정의 중요성이 부각되면서 세비에르(Xavier) 및 희(He) 초기화 방법이 도입되었다. 또한, 확률적 경사하강법(SGD)의 한계를 넘어서기 위해 모멘텀(Momentum), RMSProp, 그리고 현재 널리 쓰이는 아담(Adam)에 이르는 최적화 알고리즘의 진화가 이루어졌다. 이러한 기술적 진보는 딥러닝 모델의 학습 속도를 높이고, 복잡한 데이터 구조를 효과적으로 파악할 수 있는 기반이 되었다.

## 1. 통계학적 모형과 딥러닝 모형의 비교

전통적인 통계 모형과 현대의 딥러닝 모형은 데이터를 바라보는 관점과 구조적 복잡성에서 뚜렷한 차이를 보인다.

| 구분 | 전통적 통계 모형 (회귀/로지스틱 등) | 딥러닝 모형 |
| --- | --- | --- |
| 차원성 | 저차원 모형 (변수 수가 적음) | 고차원 모형 (수백만 개의 변수 및 모수) |
| 데이터 구조 | 생성 구조와 오차의 분리 중시 | 복잡한 생성 구조 자체의 학습 중시 |
| 복잡도 | 단순한 모형 선호 (해석 용이성) | 매우 복잡한 모형 (비선형 특성 파악) |
| 목표 | 잔차의 무작위성 점검 및 모형 완성 | 예측 정확도 극대화 및 데이터 특성 이해 |

## 2. 딥러닝의 주요 난제와 기술적 한계

신경망을 깊게 쌓을수록(Deep) 모델의 표현력은 좋아지지만, 학습 과정에서 다음과 같은 네 가지 주요 문제가 발생한다.

1. 그레디언트 소실 (Gradient Vanishing): 역전파 과정에서 가중치 수정을 위한 기울기가 점차 작아져 앞쪽 레이어의 가중치가 업데이트되지 않는 현상.
2. 초기값 설정 문제: 초기 가중치를 어떻게 설정하느냐에 따라 최적점(Global Minimum)을 찾지 못하고 지역 극소(Local Minimum)에 빠질 위험.
3. 과적합 (Overfitting): 변수가 너무 많아 훈련 데이터에는 잘 맞지만 새로운 데이터에는 대응하지 못하는 현상.
4. 학습 시간: 모델의 복잡도와 데이터 양으로 인해 발생하는 막대한 계산 비용.

## 3. 활성화 함수를 통한 경사 소실 문제 해결

과거 신경망은 생물학적 뇌의 시냅스 활동을 모방한 시그모이드(Sigmoid) 함수를 주로 사용했으나, 이는 깊은 신경망 학습에 치명적인 약점을 노출했다.

### 3.1 시그모이드 함수의 한계

* 미분값의 최소화: 시그모이드 함수의 미분 최대값은 0.25이다. 층이 깊어질수록(L승) 이 값이 계속 곱해지면서 결과적으로 0에 수렴하게 되어, 뒤쪽의 오차가 앞쪽으로 전달되지 않는다.
* 포화 문제: 입력값이 크거나 작을 경우 기울기가 0에 가까워져 가중치 업데이트가 중단된다.

### 3.2 대체 활성화 함수의 등장

* ReLU (Rectified Linear Unit): x > 0일 때 기울기가 1로 유지되어 경사 소실 문제를 해결한다. 계산이 매우 단순하여 속도가 빠르다.
* Leaky ReLU / ELU: x < 0인 구간에서 0이 되어 뉴런이 죽는 현상을 방지하기 위해 아주 작은 기울기나 지수 함수를 도입한 형태이다.
* Hyperbolic Tangent (tanh): 미분 최대값이 1로 시그모이드보다는 낫지만, 여전히 깊은 층에서는 소실 문제가 발생할 수 있다.

## 4. 가중치 초기화(Weight Initialization) 및 사전 학습

가중치를 모두 0이나 1과 같은 동일한 값으로 설정하면 모든 뉴런이 동일하게 업데이트되어 딥러닝의 의미가 퇴색된다. 따라서 무작위성을 부여하되, 층별 분포를 고려한 초기화가 필수적이다.

### 4.1 역사적 발전: DBN과 RBM

2006년 제프리 힌튼 교수는 **제한된 볼츠만 머신(RBM)**을 적층한 **심층 신뢰 신경망(DBN)**을 제안했다. 이는 비지도 학습을 통해 가중치의 좋은 초기값을 먼저 구하는 '사전 학습(Pre-training)' 방식으로, 딥러닝이라는 용어가 본격적으로 사용되는 계기가 되었다.

### 4.2 현대적 초기화 기법

현재는 사전 학습보다는 수학적으로 설계된 초기화 공식을 주로 사용한다.

* 세비에르(Xavier) 초기화: 입력 뉴런과 출력 뉴런의 수를 고려하여 분산을 설정한다. 시그모이드나 tanh 함수 사용 시 효과적이다.
* 희(He) 초기화: 세비에르 방식보다 분산을 두 배 넓게 설정한다. 렐루(ReLU) 활성화 함수를 사용할 때 최적의 성능을 보이며, 현재 가장 널리 사용된다.

## 5. 최적화 알고리즘(Optimizer)의 고도화

손실 함수를 최소화하기 위해 가중치를 수정하는 '경사하강법'은 단순 확률적 경사하강법(SGD)에서 시작하여 다양한 방식으로 발전했다.

| 알고리즘 | 특징 | 장단점 |
| --- | --- | --- |
| SGD | 무작위 미니 배치를 사용하여 속도 향상 | 경로가 지그재그로 진동하며 불안정함 |
| Momentum | 관성을 도입하여 이전 기울기 방향을 유지 | 지수 이동 평균을 통해 진동을 줄이고 빠르게 수렴 |
| AdaGrad | 변수별로 학습률을 다르게 조절 | 학습이 진행될수록 학습률이 너무 작아져 조기 중단 위험 |
| RMSProp | AdaGrad의 단점을 보완하기 위해 지수 평활 도입 | 최근 기울기를 더 반영하여 학습 지속성 확보 |
| Adam | Momentum + RMSProp | 가장 안정적이고 효율적이며 대중적으로 사용됨 |

## 6. 결론 및 향후 과제

딥러닝은 활성화 함수의 변경, 체계적인 가중치 초기화, 그리고 정교한 최적화 알고리즘의 도입을 통해 초기 신경망이 가졌던 한계를 극복해 왔다. 특히 확률적 경사하강법의 배치 처리 방식은 대규모 데이터 학습을 가능하게 한 핵심적인 전환점이었다. 향후에는 이러한 기반 기술 위에 과대 적합(Overfitting) 문제를 해결하기 위한 규제 기법들이 더해지며 모델의 완성도를 높여가는 과정이 중요하다.
